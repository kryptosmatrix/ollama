### 2.2 Proof modes — how a blueprint written before the code discharges a site obligation

Every rule below that demands a site (`file:symbol`, `file:line`) is discharged in exactly one of two modes, and the mode MUST be stated per site.

- **VERIFIED** — the site exists at `source_sha` and the grep returns it.
- **DESIGNATED** — the site does not exist yet. The blueprint names the file path to be created, the symbol to be declared, and the owning pack. Pack A converts every DESIGNATED site to VERIFIED against live source, or returns `SPEC_INSUFFICIENT` and stops.

A blueprint may be promoted with DESIGNATED sites; that is the operator's stated process, blueprint before build. A blueprint MUST NOT claim delivered behaviour, `[FULL]`, or a census count on a DESIGNATED site. A judge scoring a site rule NOT-APPLICABLE for want of code is a protocol failure: the correct score is the DESIGNATED form or a finding.

**AS-BUILT.** Where the blueprint documents code that already exists, DESIGNATED is prohibited for any site the code already has, and R-17's failure number MUST be measured **before** the promotion round. A zero, constant or empty result is BLOCKING on its face; it is not a datum to be re-measured later.

**AS-BUILT branches (operator ruling, 2026-08-11).** A blueprint is **as-built** when every behaviour it specifies is already live at `source_sha`, so its production estimate is zero. R-1.1, R-3.1, R-3.2, R-3.4 and §4's third tier question were written for build-facing documents and have no defined value there — 40 × 0 admits no document at all, so every as-built contract was BLOCKING at R-3.2 by construction. They take these branches, and only these:

- **R-1.1.** In place of a cited `[CONCEPT]` document, the blueprint carries the same three things sourced from the system: intended observable behaviour in the operator's terms, an explicit negative-space statement, and the R-17.1 failure number measured on live source before the promotion round. A concept document that does exist MUST still be cited.
- **R-3.1 / R-3.2.** The itemised production estimate is replaced by an itemised **documented surface**: every file the blueprint asserts about, with its current line count, summed. The surface is **derived, not declared** — the set of files containing the symbols the blueprint cites under R-4, re-derived by the judge by grep. A file in which the blueprint cites no symbol is not in its surface, so padding the list is self-defeating. The byte ceiling is **4 × documented LOC**, not 40. An absent or undrivable surface is BLOCKING exactly as an absent estimate is.
- **R-3.4.** Projected lines equal current lines. A documented file already over the repo ceiling carries an operator waiver or a named successor blueprint — not a split pack, because this blueprint adds no lines.
- **§4, question 3.** Read "above 300 LOC" against the documented surface. **A zero production estimate MUST NOT be used to reach Tier 1**; that would put the least build-facing documents, which are often the most load-bearing, under the smallest rule set.

Nothing else branches. R-4, R-16, R-17, R-18, R-19 and §6 apply unchanged, and R-2.2's B2/B4/B5/B6/B7 exhibits remain closure-exempt.

**The ratio is 4, and it is provisional on one measurement.** NEXUS BP01 is 91,891 bytes documenting a 25,807-line surface: **3.56 bytes per documented line**, eleven times tighter than the build-facing 40, because documenting code that exists does not require specifying what to build. 4 is set just above that single observation, so the rule constrains without retroactively failing the document it was measured on. It carries R-3.2's calibration obligation (§10).

**A document proposing any new production work is not as-built.** A mixed document takes these branches only for the sections that are, each marked individually, and itemises an ordinary estimate for the new work. Declaring as-built is a claim under R-4 and needs source evidence; a false declaration is a B2 exhibit.

### 2.3 Reach closure — the boundary that decides what can block

The **reach closure** of a blueprint is: every file it declares it will create or modify, **union** every file containing a live production producer of any input its specified algorithms consume, **union** every file containing a live production consumer of any output they emit, **union** every file containing a guard on the production write path its data traverses. One hop, enumerated by `file:symbol` in the blueprint and independently re-derived by the judge.

The closure is derived, not declared. A blueprint that omits from its closure the sole production construction site of any input its algorithms consume is BLOCKING under R-2 — that omission is exactly what converts the GSDE defect into someone else's problem.

## 3. Stages

| Stage | Artefact | Exit |
|---|---|---|
| 1. Concept | `[CONCEPT]` document | R-1 |
| 2. Blueprint | Implementation blueprint | §6 adjudication → `[IMPLEMENTATION-READY]` or a terminal exit |
| 3. Prompt packs | Pack set 0A–F | R-14 trace, `PACKS_ALLOWED_FOR_IMPLEMENTATION` |
| 4. Build and prove | Production code + tests | R-17 reality gate, including the full-system proof |

**The corpus gate (operator's stage 2).** Where the operator requires that all blueprints reach `[IMPLEMENTATION-READY]` before building begins, each blueprint is stamped against its own `source_sha`. *(The corpus-budget precondition this paragraph formerly carried was removed with R-3.3 at v2.2.0.)* A single common corpus `source_sha` is not used: it voids the moment the tree moves, and R-16.2 already scopes the void per blueprint. Each blueprint's Pack A re-verifies its own citations at the then-current HEAD before its build packs run. A corpus gate buys ordering coherence; it does not buy permanent truth.

## 4. Tiers

Answer three questions in the blueprint header. If all three are **no**, the blueprint is **Tier 1**.

1. Does it introduce or change a persisted type, schema, serialisation or wire format?
2. Does its output cross a repository, process or language boundary?
3. Is its itemised production estimate above 300 LOC?

**Tier 1** discharges R-0, R-1, R-4, R-6, R-12, R-17, R-19 and §6 only, with one judge on a substrate different from the author's, one round, no finding register. **Tier 2** discharges the whole standard. A Tier 1 judge who finds a "yes" to any of the three questions returns `TIER_MISASSIGNED`; the blueprint re-enters at Tier 2 with a fresh budget.

## 5. The rules

Each rule states the obligation, the mechanical test, and the real defect it would have caught.

### R-1 — Concept and frozen requirement set

**R-1.1** The blueprint MUST cite a `[CONCEPT]` document by path and SHA-256. The concept document MUST carry intended observable behaviour in the operator's terms, an explicit negative-space statement, and the decisions deferred to the blueprint. It MUST NOT carry type declarations, file layouts or pack decomposition.
**R-1.2** Every implementation obligation MUST be a numbered requirement carrying exactly one upper-case RFC 2119 keyword and exactly one obligation. The header MUST declare the total count N and the requirement-ID format used.
**R-1.3** Prose that is not a numbered requirement carries no obligation, and a judge MUST NOT raise a B1 or B3 finding against it — **but** B2, B4, B5, B6 and B7 exhibits block regardless of numbering (§6.2). Prose describing a live production path MUST be numbered or deleted; relabelling it `DEFERRED DESIGN` is available only for behaviour that is neither built nor specified for this pack series.

**Test.** Cited path exists and its SHA-256 re-derives; the three concept sections are non-empty. Requirement count equals declared N; every line containing an RFC 2119 keyword carries a requirement id; no id appears twice with differing text.
**Would have caught.** NEXUS BP04: 47 requirement ids against exactly one RFC 2119 keyword in 1,880 lines, with the whole delta-learning algorithm as un-numbered prose. Aevra: 121 MUST, 46 MUST NOT and 7 SHALL in wholly un-numbered prose across four active documents.

### R-2 — Reach closure and derived-requirement routing

**R-2.1** Before the first judged round the blueprint MUST publish its frozen requirement set and its reach closure (§2.3), enumerated by `file:symbol`.
**R-2.2** A finding anchoring inside the closure or to a frozen requirement blocks on its exhibit. A finding outside both is a **DERIVED requirement**: recorded with an owner and a named successor blueprint, escalated once, not repaired in place, and non-blocking. B2, B4, B5, B6 and B7 exhibits are closure-exempt and block wherever their sites lie.
**R-2.3** Re-opening the frozen set is an explicit operator act, recorded. It **consumes** remaining lineage budget (§6.3); it does not reset it.

**Test.** The judge re-derives the closure by grep — construction sites of consumed inputs, read sites of emitted outputs, guards on the traversed write path — and compares it with the published set. Any omission of a sole production construction site is BLOCKING. Findings are then partitioned by set membership.
**Would have caught.** BP81: each of ten rounds genuinely closed its predecessor's findings while the zero-guess bar surfaced roughly three new bounded edge cases one seam over; with a declared boundary the judge measures the system rather than the document and the loop is unbounded by construction. And its inverse — a NEXUS blueprint scoped to `Sources/GCDTCore/Learning/` would exclude `Sources/GCDTCore/Integration/GCDTSubstrate.swift:1083`, the sole production construction site of the gradient whose cap makes the arithmetic dead. Under R-2.3 the closure is derived and that file is inside it.

### R-3 — Volume ceilings (ANTI-BLOAT)

**R-3.1** The blueprint MUST carry an **itemised** production estimate: per pack, per file, with target line counts. A single aggregate number is not an estimate. **An absent estimate is BLOCKING in its own right**, not merely a missing comparison.
**R-3.2** Total document **bytes** — the whole file, tables included — MUST NOT exceed **40 × the itemised estimate in LOC**. The ratio is provisional, set below the measured NEXUS baseline of 51.8 bytes per production line, and MUST be recalibrated from measured actuals after the next five promoted blueprints. Exceeding it is discharged only by lossless restructuring or deletion of redundant prose, or by DECOMPOSE after §6.4a independently proves multiple features; never by raising the estimate alone or splitting one feature to escape the ratio.
**R-3.3 — REMOVED v2.2.0 (operator ruling, Ash, 2026-08-15; see the changelog).** ~~A repo MUST declare and have the operator ratify a **corpus byte budget** before its first blueprint is stamped, itemised into per-blueprint budgets. Stamping is blocked while the corpus exceeds its budget until the budget is re-ratified on the record or production LOC lands against it.~~ No corpus budget exists; nothing gates a stamp on one. Per-document volume remains governed by R-3.2.
**R-3.4** For every file the blueprint will create or modify, it MUST record current lines, projected lines, and the repo's declared ceiling. A file **already** over ceiling MUST carry either a split pack inside this blueprint's own decomposition matrix, sequenced before the pack that adds lines, or an operator waiver carrying a name, a date and the projected count. `DEFERRED DESIGN` is not available to a file already over ceiling.
**R-3.4a — the absent-ceiling branch.** A repository declares its hard numeric ceiling in its own `AGENTS.md` or `CLAUDE.md` (`Method/09_Code_Excellence_Method.md` §File Size). **Where the repository declares no ceiling, the ceiling column is recorded as `UNDECLARED` with that citation and the over-ceiling arm of R-3.4 is INAPPLICABLE** — no file can be over a ceiling that does not exist, so no split pack and no waiver is owed by that arm. The rest of R-3.4 still binds and is what the judge scores: **current lines and projected lines MUST still be recorded per file**, and an absent or underived projection is a finding exactly as before. An absent *ceiling* is not. **`[v2.3.0 PROPOSED]`.** The original justification given here was that judges cannot see the branch because it lives in `Method/09`. **An adversarial reviewer refuted that from the estate's own judge record**: `Tools/repository-judge/reviews/blueprints/rounds/de250a4/view/cursor-valid/RESULT.json` returns `CLEAR` with the evidence *"AGENTS.md declares no numeric file ceiling, so R-3.4 follows Method/09:196 and the A1/A2 file split"* — a judge read `Method/09` and discharged correctly. The findings cited as false positives were also **compound**, pairing a real itemisation defect with a ceiling remark. What survives is narrower and is why this clause is still proposed rather than withdrawn: the branch is easier to apply when it sits beside the rule. **It is not evidenced as preventing a measured false-positive rate, and the earlier text claiming so was wrong.**
**R-3.5** At pack-series closeout, estimate versus actual is recorded. A lineage whose cumulative estimate exceeds cumulative actual by more than 2× has its R-3.2 ratio halved for its next blueprint.

**Test.** `wc -c` of the document against 40 × the summed itemised estimate; `wc -l` of each named target file against the projected count, and against the declared ceiling **where one exists** — otherwise against R-3.4a. *(The corpus-budget clause of this test was removed with R-3.3 at v2.2.0 and is deleted here; it tested against a budget no repository declares.)*
**Would have caught.** Aevra: 4,849,932 bytes of architecture, one code file, zero LOC estimate anywhere in four active documents — BLOCKING at R-3.1 without any argument about ratios (and, before v2.2.0's removal, again at R-3.3 with no ratified budget). NEXUS `StateManager.swift` at 9,692 lines and `NEXUSEngine.swift` at 9,677 — nineteen times the repo's own threshold, reached one approved blueprint at a time.

### R-4 — Anchored citation

**R-4.1 (judge-enforced, NOT machine-checkable).** Every present-tense assertion about live code MUST carry `file:line`, the exact quoted token relied on, the `source_sha` at which it was verified, and the date. **This obligation is discharged by the judge reading the document, never by a script**, and a rule-coverage row for R-4.1 MUST read `FINDINGS` or `NOT_CHECKED` — never `CLEAR` on the strength of a tool run.

*Amended 2026-07-27. As originally written this rule stated an obligation nothing could verify — the defect this standard exists to eliminate. A checker can only inspect assertions that already took citation shape; a sentence reading "the kernel clamps the budget in LearningKernel" is a present-tense assertion about live code, carries no citation, and is invisible to any mechanical check however perfectly it lexes. Two independent designs reached this conclusion separately. The ambition is kept and its enforcement channel is corrected.*

**R-4.1a (machine-checkable half).** Every assertion that *does* carry a citation MUST satisfy R-4.2 and R-4.3. This is the part a script enforces, and it is the only part a tool may report `CLEAR` on.

**R-4.1b (the promise a citation check makes).** A citation check verifies that **anchors are sound** — the citation lexed, the file resolved, the line is in range, and for an ABI claim the name and value co-occur on one source line. **It does not verify that the blueprint is true.** A false claim whose token happens to appear at the cited line reads as verified, because token presence is the whole of the check. Any tool reporting under R-4 MUST state this limit in its own output, and MUST report every candidate its strict lexer rejected — an unchecked citation that reads as absent is the coverage illusion in §1.
**R-4.2** Test citations MUST name a file that exists and a function that exists. The blueprint's declared test-file list MUST be a superset of the test files that reference the symbols in its declared source files, computed by grep.
**R-4.3** Promotion FAILS on any citation that does not resolve, or resolves without containing the quoted token. Resolve-rate below 100% blocks.

**Test.** Script the citation list: open each file at each line and string-match the token. The token requirement is what makes this mechanical rather than interpretive.
**Would have caught.** BP16's "production cannot transition ARS away from `.disabled`", false at HEAD; the fifteen non-existent test-suite names cited in BP22; BP04, whose two decisive test files (`Phase207_StructuralLearningPipelineTests.swift`, `Run11LearningIntegrationTests.swift`) appear nowhere in it.

### R-5 — Status floor and coherence

**R-5.1** A label MUST NOT exceed the lowest label of any blueprint the document depends on for a load-bearing behaviour. A document-level label above its own section minimum is permitted **only** if the header enumerates, by section number, every section below it with that section's own label; an unlisted section below the document label is BLOCKING.
**R-5.2** The dependency set is **derived**: declared dependencies union every blueprint that owns a symbol cited under R-4 or declared under R-7.4, computed by grep and published with the command. Reclassifying a dependency as "not load-bearing" requires a judge-side exhibit showing no acceptance criterion depends on its behaviour. The judge MUST open each dependency document; the depending document's summary is not evidence.
**R-5.3** Before promotion the judge MUST extract every status assertion about every named subject into one table and FAIL on any incompatible pair. A family reconciliation MUST execute in one pass over all sibling documents; editing one side of a contradiction is not a reconciliation, and a repair touching one family member without emitting the family table voids the round (R-20.4).

**Test.** Build the two-column table (derived dependency, label read first-hand) and compare the minimum against the promoting label; tabulate family status tokens per subject.
**Would have caught.** BP20 `[FULL]` over a BP06 dependency at `[PARTIAL]`; BP04's whole-document `[FULL]` over its own facade header; the three BP22-family contradictions produced by same-day one-direction reconciliation passes; Aevra's three subordinates still reading "CANDIDATE … not active architecture" at HEAD while the root records them `ACCEPTED — ACTIVE`, in a root that narrates repairing exactly that defect in the fourth document.

### R-6 — Extremal arithmetic at producer-attainable bounds

**R-6.1** For every formula on an active path that contains a division, shift, floor, clamp, or a filter on its result — **or that the R-17 failure number depends on** — the blueprint MUST carry a worked-example table computed at the **minimum and maximum the live production producers can actually emit**, in the declared arithmetic, showing operands, intermediate type, division, rounding, and the exact result per cell. Formulas outside that set discharge R-6 with a single declared range per type.
**R-6.2** Each input range MUST cite, by `file:symbol`, the production producer of that input and the maximum it can emit — a literal, a clamp, or a censused observation. **A declared bound no cited producer can reach is BLOCKING**, and the example is recomputed at the producer-attainable maximum. Producers outside the blueprint's declared files are cited all the same; R-2.2 does not exempt them.
**R-6.3** Every filter, guard, clamp or `compactMap` applied to the result MUST have a survivorship row. Every scaling factor travelling alongside the value it scales MUST have exactly one declared application site named as `file:symbol`, with all other sites stated to pass it through unapplied and the payload field labelled `PRE-SCALED` or `RAW`.
**R-6.4** If any producer-attainable cell evaluates to zero, to the no-op value of the downstream operation, or to an empty collection, that is BLOCKING — unless the blueprint declares it intended and names the consumer that handles it.

**Test.** Two passes. (a) Enumerate every value-transforming step in every algorithm section, **prose steps included**, and require a worked row per step in the R-6.1 set. (b) Grep the files in the reach closure over the cited function ranges for `/`, `*`, `>>`, `filter`, `guard`, `compactMap`; every hit must appear in a worked-example or survivorship row. A source-side operator with no blueprint row is BLOCKING. The judge recomputes each cell.
**Would have caught.** The most expensive defect in the estate, by arithmetic alone. `DeltaLearner.swift:260` computes `Int64(entry.value) * Int64(effectiveLRMicro) / 1_000_000`; the producer caps the signal at 100 (`GCDTSubstrate.swift:1083`) or 50 (`:1098`); `baseLearningRateMicro` is 1000 with a maximum 5× phase multiplier. Producer-attainable maximum product 500,000; integer division by 1,000,000 = 0; `.filter { $0.value != 0 }` at `:263` empties the array. The max-input row is two lines and prints 0. R-6.2 is the clause that reaches across the module split to fetch the cap; R-6.3 separately catches the R-A2 Hebbian double-scaling that turned a +25 accumulator into a saturation switch.

### R-7 — Representation adequacy

**R-7.1 (adequacy).** For **every frozen requirement**, the blueprint MUST name the exact type, enum case, field or relation that carries it — VERIFIED or DESIGNATED — and exhibit one encode/decode round trip over a worked instance. An effect with no carrier is BLOCKING. The handoff capsule's carrier rows MUST be a superset of the effects named in the activation-proof tables.
**R-7.2 (cannot represent).** Every blueprint whose normative content **depends on** a type, enum, schema or relation vocabulary — authoring it is not required — MUST carry a **Cannot Represent** table for the subset its data traverses, or cite a custodian blueprint's table by section and SHA-256. The table states: every declared case no specified path produces, marked `NOT PRODUCED` with its consequence; every place N distinct domain relations collapse onto one representation, with what the collapse forecloses; and five concrete statements from the problem domain the encoding cannot express. **The five statements are supplied by the judge, not the author.**
**R-7.3 (custody).** Every vocabulary a blueprint depends on MUST have exactly one custodian blueprint carrying R-7.2 for it. Where none exists, the first dependent blueprint's promotion is BLOCKED until one is authored.
**R-7.4 (declaration).** Every symbol the blueprint references MUST resolve either to a declaring blueprint carrying a complete declaration, or to live source under R-4. If neither resolves, the verdict is `SPEC_INSUFFICIENT`, not a repair.
**R-7.5 (foreclosure bites).** A foreclosure declared under R-7.2 or R-8.2 that intersects any frozen requirement is BLOCKING. Disclosure is not discharge.

**Test.** Set difference of activation-proof effect rows against capsule carrier rows; set difference of declared cases against activation-proof rows that emit them; grep every capitalised symbol for an owning declaration or an R-4 citation; intersect the declared foreclosures with the frozen requirement set.
**Would have caught.** The 2026-07-15 double-judge `NOT_READY`: six actions unrepresentable in the existing type system, reducer state with zero new payload cases (R-7.1). The NEXUS graph's four zero-instance edge kinds and the collapse of instanceOf / subtypeOf / part-of onto one case with no relation-label field, so `hasProperty(A,B)` is unrepresentable (R-7.2) — a table that exists nowhere in the corpus because `EdgeType` is declared only at `Sources/GCDTCore/Types/EdgeType.swift:4` and `grep -rn EdgeManager docs/blueprint/` returns zero, which is precisely what R-7.3 forbids. `ArcheCheckpointLoaderProvenanceSeal`, referenced by five ARCHE blueprints and declared nowhere, consuming thirteen rejected BP19 cycles (R-7.4).

### R-8 — Write-path admission audit

**R-8.1** The blueprint MUST carry a **Write-path Guards** table whose rows are the complete set of guards, preconditions, capacity checks, clamps, truncations, top-N cuts and rejection arms on the production write path its data traverses — **enumerated by `file:line` across the whole reach closure, whether or not this blueprint modifies those files** — with, per row: the constant and its value, the **current live or shipped workload value** for that quantity, behaviour on breach, and whether the breach is observable. An empty table is BLOCKING; the enumeration itself is a coverage set and is asserted under R-13.4.
**R-8.2** Each row MUST carry a non-empty **Forecloses** cell naming the class of system behaviour that guard makes permanently impossible. Where any declared type or case's own documented semantics require the structure a guard refuses, that is a B2 exhibit and BLOCKING.
**R-8.3** A cap below the live workload without an explicit disposition is BLOCKING. Every reject, drop, clamp, skip or early return MUST increment a named observable or emit a named reason code, and an acceptance criterion MUST read it. A drop invisible to every counter, log and digest is BLOCKING. An operation that drops data MUST NOT report success unless the loss is a first-class field.
**R-8.4** Every limit MUST have a named acceptance fixture whose input **exceeds** it. A limit whose proof fixture cannot reach it is not proven.

**Test.** Grep the reach closure for `guard`, `precondition`, `return false`, `continue`, `*Limit`, `*Cap`, `max*`, `min*`; every hit is a row; compare value against live-workload numerically; check each row's Forecloses cell is non-empty and each drop names an observable.
**Would have caught.** The DAG-by-construction limit: `EdgeManager.swift:40-41` rejects any edge that would close a cycle and `:190` rejects self-loops, so no recurrent circuit is constructible anywhere in NEXUS — a system-wide foreclosure stated in no document. Sharper still, `EdgeType.swift:11` declares `case temporal` as "Carries recurrent hidden state", which that guard makes unreachable: a clean B2 exhibit thirty lines from its own refutation, with zero temporal edges over 188,280 shipped nodes. `EdgeManager.createEdge` returns `false` silently at five sites (`:29,32-35,37,41`) behind `@discardableResult`. `largeGraphJSONPayloadNodeLimit = 50_000` (`PersistentCheckpointStore.swift:109`) against a shipped 188,280-node graph. The FOUNDRY→NEXUS loader keeping 125,606 of 303,323 edges with `report.success == true` and a golden fixture of 184 edges that could never breach the cap (R-8.4).

### R-9 — Reach, readers and instance census

**R-9.1** Every field, payload case, proposal kind, receipt, config flag and score the blueprint introduces or relies on MUST name (a) a production construction site **at level REACHABLE** — a call chain from a named production entry point with each hop cited, VERIFIED or DESIGNATED — (b) at least one production read site whose behaviour changes as a function of the value, and (c) the observable that changes. A read site whose sole effect is a digest, hash, log, counter or telemetry field does **not** satisfy (b) unless a named acceptance criterion branches on that observable and exercises the branch organically.
**R-9.2** Existence claims are classified at exactly one of **DEFINED** (a declaration), **CONSTRUCTED** (a production construction site), **REACHABLE** (a cited call chain), **INSTANTIATED** (a count in live or shipped data). The strongest claim permitted is the weakest level with evidence. An item that cannot reach REACHABLE MUST be labelled `DEFERRED` with a named owner blueprint and MUST NOT count toward `[FULL]` or `[IMPLEMENTATION-READY]`.
**R-9.3** A blueprint that **specifies a producer** for any case of a typed enumeration, schema or tag — not merely one that claims instances exist — MUST census that case against the current shipped artefact: count per case, total, artefact path and SHA-256, and the reproducing command. **A specified producer with zero live instances is BLOCKING** unless declared intended with a named tolerant consumer. Where the artefact does not yet exist, the census is DESIGNATED and Pack A runs it.
**R-9.4** Any score, metric or flag the design branches on MUST be traced from computation site to every reading branch. Where the computation is a literal constant on the production path, every branch conditioned on it is marked `UNREACHABLE-ON-PRODUCTION-PATH` and no document may claim those branches as delivered behaviour.

**Test.** Per item: a construction grep excluding tests, a call-chain trace to a production entry point, a read grep, and a check that the named observable appears in the acceptance criteria. Re-run the census command against the named artefact and compare counts. For each branch condition, open the operand's computation site and check for a literal.
**Would have caught.** BP04's `updatedDelta`: constructed at `DeltaLearner.swift:360/:376`, read by nobody — its sole caller keeps only `newChainDepth` (`GCDTSubstrate.swift:1119-1121`), so even a non-zero delta never lands. The 231-kind wiring sweep's 50 orphan payload kinds with live reducer handlers and zero production construction sites; the thirteen confirmed facade rows; `priorityAdjustment` with no live consumer, flagged convergently by both judges on 2026-07-15. The typed-edges "Claim B", an enum definition mistaken for a capability — "technically true and practically the most dangerous error of the four". BP04 §15.1 specifying a `.dataFlow` co-activation producer that has produced zero of 60,647 shipped edges (R-9.3). `GraphCandidateGenerationKernel.swift:358/:419` hardcoding `let contradiction: Int32 = 0`, making the Stage-2 rejection at `> maxContradictionScore` unreachable across BP22, 22A and 22B (R-9.4).

### R-10 — Organic activation

**R-10.1** For every gate, flag or mode whose default is closed or disabled, the blueprint MUST name the production emitter that moves it off the default, as `file:symbol`, VERIFIED or DESIGNATED.
**R-10.2** Every acceptance criterion MUST be labelled `ORGANIC` or `INJECTED`. Each feature MUST carry at least one `ORGANIC` criterion: it opens the gate by driving the production entry point alone, with production configuration, **zero injected state, and input produced by the cited production producer rather than hand-constructed**. A test that constructs the open state, or that hand-feeds a magnitude no producer can emit, does not discharge this.
**R-10.3 — the paired enabled-path observation (added v2.3.0, operator ruling, Ash, 2026-08-22).** Where a blueprint's proof rests on a **disabled-mode parity baseline** — a committed fixture asserting that the feature, when off, changes no digest, no byte stream and no observable — it MUST also carry a **paired enabled-path observation**: a counter, a call log, an invocation seam or an equivalent instrument showing the feature's code **ran** when the gate was open, in the same test file or a named sibling.

The reason is arithmetic, not taste. A disabled-mode parity test **cannot fail because the feature's own logic is broken**; it fails when the feature is enabled, or when something off-path — gating, persistence, shared state — regresses into the digest. Neither of those is the feature working. Unpaired, it prices staying disabled at zero and prices enabling at a fresh proof obligation, and a corpus under that gradient converges on every gate shut. Worse, it is passed identically by a kernel that runs and has all its proposals rejected — a facade in exactly the shape KANON 4 names.

The worked example is NEXUS `Tests/NEXUSTests/CILDisabledNonInvocationTests.swift`, which instruments `NEXUSEngine.pack17_00_subphaseCallCounters` and pairs the disabled-zero assertion with an enabled-increments assertion, in its own words *"else the disabled-mode zero assertion would be vacuous."* Where the baselines of several features are **byte-identical to each other**, they are one recorded trace re-filed under several numbers and count as **one** observation, not several; the judge reports the identical set by hash and each affected blueprint owes its own paired observation regardless.

**Test.** Grep the reach closure for a constructor of the proposal or config that flips each gate; zero hits with no DESIGNATED site is BLOCKING. Read the ORGANIC criterion and confirm it references only the production entry point and names the producer of its input. For each disabled-mode baseline fixture the blueprint cites, find the paired enabled-path observation and confirm three things: it asserts on the **same feature** the baseline pins; the enabled arm asserts a value that is **non-zero or present**; and the disabled arm asserts that same value is **zero or absent**. An assertion that only shows the code ran, without a disabled-arm counterpart on the same value, does not discharge R-10.3. An unpaired baseline is a **B5 exhibit** — FACADE-PASSES, with the twin named in the rule's own rationale: a kernel that runs and has every proposal rejected satisfies the disabled-mode criterion set exactly. Hash the baseline fixtures the corpus cites and report any that are byte-identical to one another.
**Would have caught.** The whole BP22 four-gate promotion lane: nothing under `Sources/` ever constructed the calibration proposal, `gateSummary` is written only by `applyWorldModelCalibration` (`StateManager.swift:7746-7754`), and the default is `.allClosed` (`WorldModelTruthSurfaceRegistry.swift:154`) — four routes documented as LIVE, provable only under test-injected state. BP16 ARS, unenableable because `ARSRuntimeConfigProposal` is constructed only in tests.

### R-11 — Deployment matrix and recovery

**R-11.1** For every scheduled, conditional or event-driven behaviour, the blueprint MUST table each **shipping** deployment configuration (app, headless, server, CLI, test) against each trigger that can arm it, and prove activation in every configuration that ships. Where a precondition is written by a component disabled in some configuration, that configuration is named and its behaviour stated.
**R-11.2** Every failure, retry, abstention or degraded path MUST name the concrete component that **re-triggers** the work and carry an acceptance test that induces the failure and observes recovery with no further external input. "Will retry on the next pass" is not a mechanism.
**R-11.3** Where output is installed, exported or committed, acceptance MUST be demonstrated against the artefact the consumer actually executes or reads, identified by content — a digest, or by interrogating the artefact — never by path, filename, timestamp or build-tree location. A committed fixture is verified from the committed blob (`git cat-file blob HEAD:…`), not the working tree.

**Test.** The configuration × trigger table exists with a proving test cited per shipping `Yes` cell; every failure branch carries `recovered by:` plus an induce-and-observe test; every acceptance command names a deployed artefact and a content identity.
**Would have caught.** SixHats OWL-115: headless attribute decay could never fire on any MCP-opened scope, because the server constructs every store with `armDecayTimer:false` (`ScopeStoreRegistry.swift:116`). OWL-094: `ConsolidationRunner`'s comment promised a retry with nothing scheduling one — and the judge had reviewed that exact site and accepted the failure shape. The stale `~/.local/bin/agora-memory-mcp` copy serving an old tool set to four harnesses. The golden test that passed green while its `.gcdt` fixture was gitignored and never committed.

### R-12 — Degenerate twins and value-bearing criteria

**R-12.1** Every feature MUST name its **degenerate twins** — real, fully wired implementations that emit nothing: zero, no-op, constant, empty-collection, identity-passthrough, abstain-always, **correct-but-unreachable** (the implementation with its production call site removed), and **correct-but-producer-starved** (the implementation fed only values the cited live producers can emit). Naming the twins is BLOCKING and is dischargeable before any code exists.
**R-12.2** For each twin, the exact killing assertion with expected and actual values. Where no implementing pack exists yet this is MAJOR; once one does it is BLOCKING.
**R-12.3** At least one acceptance criterion per behaviour MUST assert a **value**, and the asserted quantity MUST be the one named in that feature's activation-proof "Observable effect" row, or a stated function of it. A literal-value assertion on a metadata or configuration field returned alongside the output does not discharge this. Criteria whose only assertions are element count, identifier, type identity, non-nil, or symmetric equality between two computed sides are BLOCKING as sole proof.
**R-12.4** Every criterion asserting a computed result MUST state one metamorphic relation the correct implementation satisfies — monotonicity, scaling, idempotence, order-invariance — and every load-bearing test MUST carry one named mutation with the assertion expected to fail. A fixture's discriminating property is stated as "this fixture distinguishes X from Y because ⟨property⟩"; "valid" and "representative" are not properties.
**R-12.5** If the full criterion set would be satisfied by a stated twin, that is BLOCKING and the blueprint cannot rise above `[SPEC-DRAFT]`.

**Test.** The judge writes the shortest hollow implementation satisfying every stated criterion and names the criterion that rejects it; if none does, that is the exhibit. Then checks each value assertion's subject against the activation-proof observable row.
**Would have caught.** The zero-delta GSDE implementation, which passes the live suite: `Phase207_StructuralLearningPipelineTests.swift:172-192` asserts only count and nodeID; `Run11LearningIntegrationTests.swift:91-134` passes if both compared sides are zero. BP04 §13.6's three named facade-fail tests, all of which pass with a permanently empty `updatedDelta`, because each asserts a metadata field (a learning-rate ratio, `entries.count ≤ K`, a depth increment) rather than the payload — R-12.3 is the clause that catches a real literal-value assertion aimed at the wrong quantity. `GraphCandidateGenerationTests.swift:712-717`, "proving" contradiction abstention by setting `contradictionTolerance: -1` against a hardcoded-zero score.

### R-13 — Measurement scope, instrument capability and coverage

**R-13.1** Every invariant claim — determinism, idempotency, ordering, replay fidelity, byte-equality — MUST state the scope at which it is **asserted** (in-process, cross-process, cross-machine, cross-version) and, per cited test, the scope at which that test **measures**. A narrower tested scope is recorded as a named open item and the invariant MUST NOT be claimed wider.
**R-13.2** Any determinism or replay claim MUST declare, for every sort, dedup, grouping, capping and digest, a total-order key whose final component is a unique identifier; MUST name every hash entering state and assert it is process-stable; and MUST state how non-String-keyed dictionaries and Sets are canonicalised in digest material.
**R-13.3** Every acceptance gate MUST name its **instrument** — exact command, flags, pass token — and carry a capability demonstration: the instrument's output on a known-bad input and on the known-good input. A gate whose instrument cannot in principle observe the class it claims to cover is a facade gate and blocks. Every test names the host capability it requires; a test that **skips** yields `NOT-PROVEN` and MUST NOT count toward acceptance. Every recorded proof carries an environment fingerprint.
**R-13.4** Any repository-wide, corpus-wide or set-wide check MUST emit its **coverage set** as data and assert a non-zero, independently derived expectation over it. Exemptions are an enumerated named list, never silence; widening an exemption to clear a failure is not a fix; a zero-finding result over a zero-size coverage set is a FAILURE.

**Test.** For each invariant, read the cited tests and record whether the two compared artefacts are produced in the same process, machine and binary. Check the host-capability column and the skip rule. Check the specified check returns its scanned set and a test asserts a member or count of it.
**Would have caught.** The First Directive broken at HEAD in the default configuration and undetected by ~6,300 tests: `LOGOSEngine.swift:164` seeds from `String.hashValue`, breaking cross-process replay from pulse 3, while every determinism assertion compared two runs inside one process sharing one hash seed (`W0LongitudinalEvaluationTests.swift:49-57` does so by construction). ARCHE BP19's gate mandated `-typecheck` while claiming to check region-based isolation — a SIL pass `-typecheck` never runs — and would have emitted `BP19_COMPLETE_SENDABLE_GRAPH=PASS` while structurally blind to its advertised defect class (R-13.3). POIESIS R-05, blind for two months over 298 pack files because a non-recursive glob's empty result was read as evidence (R-13.4). The ~38 ARCHE items stuck at `[MVP]` solely because the load-bearing activation test was Metal-skipped on the audit host.

### R-14 — Bidirectional trace

**R-14.1 (pre-code, primary).** Every frozen requirement id MUST appear verbatim in at least one acceptance criterion id, and every acceptance criterion MUST cite a requirement id. Set equality is asserted in both directions with the published grep command and its expected output. **This is the highest-yield pre-code check in the standard and is never NOT-APPLICABLE.**
**R-14.2 (post-code).** Every requirement id MUST appear verbatim in the pack that implements it and in at least one test name or test-file annotation; every production file or test a pack introduces cites a requirement id or is declared derived, and derived items return to the blueprint before the next pack set.
**R-14.3** The requirement-to-pack matrix MUST have, for every load-bearing requirement, both an **implementing** and a **proving** pack. An empty cell blocks.

**Test.** Run the published grep; the returned id set must equal the declared set in both directions, with the difference reported each way.
**Would have caught.** Aevra, in one grep: 37 numbered invariants in ARC-001 and 127 numbered acceptance criteria in VER-001, the two id universes **disjoint in both directions** — 68,373 lines of prose never closed into a provable loop. NEXUS BP04: `R-04-` appears ten times across `docs/prompt-packs/` and zero times under `Tests/`. ### R-15 — Boundary crossing

Applies only where output crosses a repository, process, language or serialisation boundary.

**R-15.1** The blueprint MUST name the consumer's entry point at a pinned revision and mandate a golden artefact produced by the **real production path** and consumed by the **real consumer entry point**, with the consumer-side expectation derived from the **source data** — never by replaying the producer's model of the consumer.
**R-15.2** Every enumeration, tag or type code crossing the boundary MUST be a **total** mapping with a per-value census of live carriers; unknown values fail loudly with a named error. A catch-all default arm on a boundary decode or encode is prohibited unless the blueprint names the value it means and proves no other value can reach it.
**R-15.3** Every identity, digest or provenance check MUST be computed from live production values at run time and validated under the **consumer's** semantics. Constant-versus-constant comparisons and schema-shape checks standing in for semantic checks are prohibited; the blueprint names at least one falsifier of the form "schema-valid but semantically hollow input is REFUSED".
**R-15.4** Every external normative reference — a sibling repo's HEAD, an upstream contract, a rules document, a script path, a model — MUST resolve at the named revision, be pinned by content digest, and carry a re-verification command. Every self-referential constant inside the document (edition, version, protocol identifier) MUST equal the document's own declared value.

**Test.** Grep for a named consumer symbol + `file:line` + revision; check one test invokes both production entry points with source-derived expectations; check the enum table is total with a falsifier feeding an unmapped value; extract every path, URL, digest and self-referential constant and assert each resolves or matches.
**Would have caught.** No FOUNDRY export had ever been loaded by NEXUS until 2026-07-16 despite years of both suites passing: the producer mirrored the consumer's aggregator and was wrong by a factor of ten (`BootstrapLoader.swift:524/:539`), while NEXUS's own tests hand-built bytes matching a retired repo's writer. `writer.py:91` mapping unmapped edge types to byte 0 and `GCDTBridge.swift:84` decoding unknown types as `default: return .semantic  // Safe default`, together erasing 128 of 184 golden-fixture edges. Aevra ARC-001 v1.2.1, whose front matter says 1.2.0, whose §2 says 1.2.1, and whose normative envelope rule fixes `governing_document_edition="1.1.0"` — so every event hash in a conforming implementation would bind a string two editions stale (R-15.4).

### R-16 — Stamp validity

**R-16.1** An ordinary EARNED stamp MUST record the blueprint's content SHA-256, the repo HEAD SHA at judgement (`source_sha`), the paths of both judge artefacts with substrates, verdicts and dates, the baseline failure number, and **whether every collected judge artefact has been adjudicated**. A review run and not read is worse than one never run: it manufactures the appearance of scrutiny.

**[PODT-V1]** While the exact amendment payload is externally ratified, a post-obligation promotion MUST instead carry every required core field in Annex 16A §7.

**R-16.2** The ordinary stamp is **VOID for build packs** — recon and spec packs remain permitted and are the designated repair channel — if the content hash differs from the recorded one or if any cited `(file, line, token)` triple no longer resolves under the R-4.3 test.

**[PODT-V1]** An Annex 16A promotion is additionally void when its TECHNE ratification, object custody, source authority, execution evidence, register history or later-event checks fail under Annex 16A §8.
**R-16.3** Re-promotion requires a fresh judged round against the new bytes, not an amendment note. A status-only patch MUST include a mechanical check that every self-referential constant equals the new value (R-15.4), and is invalid single-substrate.

**Test.** `git log -1 --format=%H` and the content hash against the recorded values; re-run the R-4 citation script at HEAD.
**Would have caught.** BP59's two 2026-06-24 PASS artefacts judging the text as it stood before three material repairs on 2026-07-12 — "the stale PASS artefacts make BP59 look execution-ready; it is not". Aevra ARC-001, whose only dual-substrate review targets now-archived bytes with 306 collected findings unread, while the document carries `ACCEPTED — ACTIVE`.

### R-17 — Failure number and reality gate

**R-17.1** Every blueprint MUST open with one paragraph of outcome in the operator's terms and one **failure number**: the measurement which, if observed after implementation, means the feature did not work — with units, instrument, and the exact command. It is measured on HEAD at promotion (the baseline) and re-measured at the reality gate. Under AS-BUILT (§2.2) it is measured before the promotion round and a zero, constant or empty result is BLOCKING on its face.
**R-17.2** After each feature is implemented the declared **full-system proof set** MUST run — not "existing relevant tests" — recorded with the R-13.3 environment fingerprint and pass, fail and skip counts.
**R-17.3** Scoping the run below the declared set requires an operator-recorded waiver naming what was not run. A known-red baseline is recorded as such, never hidden behind a focused run.
**R-17.4** A wrapper's exit code is not the build's. The proof record carries the compiler's or test runner's own exit sentinel, echoed explicitly.

**Test.** The failure number, unit, instrument and command are present; the judge runs the command on HEAD and records the baseline; at closeout the recorded command matches the declared set or a waiver exists.
**Would have caught.** GSDE delta learning emitting exactly zero: a failure number of "sum of absolute committed delta entries after N pulses MUST be > 0" fails on day one, before any judged round, and under AS-BUILT blocks immediately — for roughly 3% of the standard's total cost. ### R-18 — Judge independence

**R-18.1** No agent, session or model instance that drafted or repaired any part of a blueprint may emit `BLUEPRINT_JUDGE=PASS` for it.
**R-18.2** Judges receive the document text, this standard, **the repo at `source_sha`, every document R-5.2 requires them to open**, the frozen requirement and closure lists, and the finding register (ids, anchors, status only). They MUST NOT receive the author's reasoning, prior verdicts, or prior judges' arguments. **A round whose judge was denied any document R-5.2 requires it to open is `PROTOCOL-INVALID`: it does not count toward the §6.3 budget and MUST be re-run.** Withholding the author's reasoning is correct; withholding the corpus manufactures false CLEARs.
**R-18.3** **Blocking requires one judge with a valid exhibit. Passing requires two judges on different substrates, against the same `document_sha` and `source_sha`, each with zero BLOCKING.** Verdicts are never averaged or put to a majority. A same-substrate PASS is never evidence of readiness and MUST NOT count in any round where a different-substrate judge returned findings on the same bytes.
**R-18.4** At least one judge's mandate MUST be independent **tracing**: locating declaration sites, persistence and checkpoint paths, async and boundary crossings, write-path guards and the production emitter of every gate. A report whose citations are a subset of the blueprint's own is a citation-verification pass and does not satisfy this.
**R-18.5** Findings from all instruments are **unioned**. Agreement is not required and is not sought.

**Test.** The judge artefact records identity, substrate, `document_sha`, `source_sha`, and the context it was given; cross-check against the repair ledger and the lineage `.identity.json` — any name in both voids the PASS. Check the report cites at least one `file:line` the blueprint did not.
**Cost.** Two substrates per round is real token and wall-clock cost. **What it buys:** BP81's own natural experiment — the same-substrate judge returned ready for rounds 6 through 10 while the different-substrate judge returned 0, 3, 2, 3, 3 on the same bytes, including a non-existent enum declaration site that would have crashed at runtime.
**Would have caught.** The 2026-07-15 NEXUS blueprint that self-declared `[IMPLEMENTATION-READY]` and was judged `NOT_READY` by two independent judges on six convergent findings. BP04's §35, a self-judgement emitted by the same rewrite pass recorded at its own line 1693. Aevra's four adversarial rounds, every one conducted with all four subordinate documents withheld from the judge, which is why three siblings' contradictory self-status survived all four.

### R-19 — Exhibit-bearing severity and full coverage

**R-19.1** A finding is **BLOCKING** if and only if the judge names its test and supplies the exhibit:

| Test | Name | Required exhibit |
|---|---|---|
| B1 | CONTRADICTION | Both irreconcilable normative statements quoted |
| B2 | IMPOSSIBILITY-AT-SOURCE | A live `file:line` that refutes the instruction |
| B3 | UNDETERMINED-OUTPUT | Two conforming implementations exhibited, producing different persisted bytes, public results or digests |
| B4 | UNDECLARED LOAD-BEARING SYMBOL | A symbol an acceptance criterion or public signature depends on, neither declared nor resolvable to a cited `file:line` |
| B5 | FACADE-PASSES | The twin implementation named, plus the criterion set it satisfies |
| B6 | ARITHMETIC-DEAD | A worked extremum showing a formula is constant, saturated or empty over its **producer-attainable** input ranges |
| B7 | COMPOSITION-DEAD | An ordered chain of two or more cited `file:line` sites, each individually conforming, whose composition yields a constant, empty or no-op result at the producer-attainable extremum |

**R-19.2** Everything else real is **MAJOR** — non-blocking, but a numbered build obligation bounded under §6.5 — or **MINOR**, advisory. A BLOCKING finding without a named test and exhibit is demoted to MAJOR.
**R-19.3** The report MUST contain one row per rule of this standard at the blueprint's tier, valued `CLEAR` (with one line of evidence), `FINDINGS` (anchored, with an exhibit if BLOCKING), or `NOT_CHECKED` (with the reason). `BLUEPRINT_JUDGE=PASS` MUST NOT be emitted while any row reads `NOT_CHECKED`. This coverage record is the input to §6.2's byte-keyed rule.
**R-19.4** Judges emitting a foreign severity vocabulary (DEFECT / CONCERN / NOTE, HIGH / MEDIUM / LOW) are **recounted from exhibits, not from labels**: a DEFECT without a B-exhibit is MAJOR, a CONCERN with a B2 exhibit is BLOCKING.

**Test.** Row count equals the tier's rule count; every BLOCKING carries `blocking_test` and `exhibit`; a second judge re-runs only the exhibit — are both quotes present and contradictory, does the cited line say what is claimed, do the two outputs differ, does the extremum recompute, does the chain compose to a no-op. Disagreement then concerns a fact.
**Would have caught.** GSDE zero-emission under B6, a two-line calculation no rule ever demanded. The FOUNDRY 58.6% edge drop and the D-9a inert sweep under B7 — the class where every individual site is correct and the chain is dead, which B2 alone cannot exhibit. The 2026-07-15 blueprint's missing per-feature falsifiability structure and dead field, both inside the existing attack list, on a document promoted with no coverage record showing they were ever attacked.

### R-20 — Finding register and repair containment

**R-20.1** Each blueprint carries one **append-only** register (`<blueprint>.findings.json`). **The orchestrator, not the judge, assigns ids** (`BP81-F-0007`), once, at first appearance, never reused or renumbered; round-local `F-1` numbering is prohibited. **One finding = one B-exhibit anchored to one frozen requirement or closure entry; two findings sharing an exhibit are one.** The orchestrator de-duplicates by exhibit before computing `new_blocking` and publishes the de-duplication as data. Each entry records `first_seen_round`, `first_seen_sha`, `severity_at_first_seen`, `blocking_test`, section, anchor quote, status (`OPEN | CLOSED | OBLIGATION | NARROWED | WITHDRAWN`), `closing_sha`, `introduced_by_sha`.
**R-20.2** Every round after the first MUST return, per `CLOSED` entry whose anchor still exists, either `CONFIRMED_CLOSED` or `REOPENED` with a quote. A missing entry is a protocol failure and the round is re-run.
**R-20.3** Every repair round MUST produce a **carry-over audit**: one row per previously-closed finding (`STILL-CLOSED` / `REOPENED`) and one row per load-bearing item — type, constant, field, formula, invariant, criterion id — marked `KEPT`, `CHANGED-with-reason` or `INTENTIONALLY-DROPPED-with-sign-off`. A repair that cannot enumerate is not a repair. This applies to status-only patches: a patch that enumerates four corrections without enumerating the population it drew them from is not a repair.
**R-20.4** A repair round MUST change only the sections named in the findings it discharges; a heading changed outside that set voids the round. A repair that touches one member of a document family without emitting R-5.3's family table also voids the round.
**R-20.5** A repair round adding more than **150 lines** requires operator approval before the next round is dispatched. Content mandated by R-6, R-7.2, R-8.1 and R-12.1 is **exempt** from that trigger: the growth budget must not tax the rules that carry the standard's protective value. Closing a finding by **deleting or narrowing** an unhonourable claim is a first-class closure, recorded `closed_by: NARROWED`, and is preferred whenever both close the finding. Each repair commit closes exactly one register id and names it in the subject.
**R-20.6** The judge report field is `required_property` — the determinacy or invariant the document must acquire — not `required_fix`. A judge MUST NOT prescribe a mechanism, and a repair agent MUST NOT treat a prescribed mechanism as authority.

**Test.** Diff the register between rounds: no id changes meaning, none reused, every `CLOSED` carries a `closing_sha` and appears exactly once in the next report. `git diff` the blueprint: changed headings ⊆ headings cited in the discharged findings; insertions − deletions > 150 requires a recorded approval. Scan `required_property` for imperative design verbs.
**Would have caught.** BP81's round 6→7 regression: round 6 reached 0 BLOCKING, then its own +259-line repair created a routing-without-apply crash window and dropped `trainingPermissionRaw` from the registry digest, going back to 3. The round-6 silence: round 5's report already contained the round-7 defect verbatim, the repair fixed only half, round 6 raised nothing, round 7 re-raised it BLOCKING — one full round lost for want of a register. Two judge-prescribed defects: round-6 F-7 ordered the split that became round-7 F-3; round-7 F-4 ordered the propagation that became round-10 F-2.

## 6. Termination

### 6.1 Definitions

An **adjudication** is an ordered sequence of judged rounds over one blueprint, each against a frozen `document_sha` and `source_sha`. `new_blocking(N)` is the count of BLOCKING findings registered in round N not already in the register — a set difference over the append-only register, computed by the orchestrator after exhibit de-duplication (R-20.1), with no judgement involved.

### 6.2 Admissibility

- A finding MUST anchor inside the reach closure or to a frozen requirement, or it is DERIVED and non-blocking (R-2.2).
- A finding MUST carry a B1–B7 exhibit to be BLOCKING, or it is MAJOR (R-19.2).
- **Precedence.** B2, B4, B5, B6 and B7 exhibits block regardless of (a) whether the text they cite is numbered, (b) whether the sites they cite lie inside the declared closure, and (c) when they were first noticed. A fact about live source or about what the criterion set admits does not become less true for having been missed once, nor for being described in prose the author chose not to number.
- **Byte-keyed rule.** A **B1 or B3** finding first raised in round N against text unchanged since round N−1's `document_sha` is admissible only as MAJOR — **and only where round N−1's coverage record (R-19.3) reads `CLEAR` for the rule under which it is filed.** Where round N−1 read `NOT_CHECKED` or did not cover that section, the finding keeps its exhibit-derived severity. Reader variance is a discriminator only where the earlier reader actually looked.
- **Regressions always block.** A finding whose `introduced_by_sha` falls inside this adjudication's repair range blocks, must be closed before pack authoring, and is exempt from the byte-keyed rule.

### 6.3 Budgets

- **Lineage budget: 8 judged rounds per blueprint id**, spanning every adjudication, re-adjudication after REJECT, and scope re-open. A scope re-open **consumes** budget; it does not reset it. When the lineage budget is exhausted the only permitted exits are EARNED, OBLIGATIONS, DECOMPOSE or terminal REJECT — never another round.
- **Per-adjudication cap: 5 rounds.** Round 6 of an adjudication does not exist.
- **Ratchet:** for any N ≥ 3, if `new_blocking(N) > 0` **and** `new_blocking(N) ≥ new_blocking(N−1)`, the adjudication ENDS at round N. A zero-zero sequence is convergence, not failure: it routes straight to the EARNED check with no escalation.
- Tier 1 (§4) has a budget of one round.

### 6.4 The four terminal exits

| Exit | Precondition | Result |
|---|---|---|
| **EARNED** | Two judges, different substrates, same `document_sha` and `source_sha`, zero BLOCKING each; zero open regressions; **at most 5 open obligations, each bounded per §6.5** | `[IMPLEMENTATION-READY]`, `PACKS_ALLOWED_FOR_IMPLEMENTATION` |
| **OBLIGATIONS** | At most 5 residual BLOCKING findings, every one bounded per §6.5 | `[PACK-READY]`, `PACKS_ALLOWED`; header states `[IMPLEMENTATION-READY]` was NOT earned |
| **DECOMPOSE** | Every required judge — one at Tier 1, two at Tier 2 — satisfies the feature-boundary test below against the same matrix and operator approves the child set | Children declared; parent → `[ARCHIVAL]`; each child gets its own 8-round lineage budget |
| **REJECT** | §6.4a does not earn DECOMPOSE, and either the tier's required judge panel unanimously places the earned level two or more rungs below declared, residue exceeds 5, any residual is unbounded, or one section produced BLOCKING findings in three consecutive rounds | `[SPEC-DRAFT]`; rework starts from the judge reports, not the current text; if budget remains, whole affected sections and their seams may be reconciled under the same id; at zero remaining rounds this is terminal |

Decomposition is permitted **once per blueprint lineage**. A child that would decompose again exits via OBLIGATIONS or REJECT.

**Exit precedence is deterministic:** DECOMPOSE if and only if §6.4a is earned and operator-approved; otherwise REJECT if the tier's required judge panel unanimously places the earned level two or more rungs below declared; otherwise EARNED; otherwise OBLIGATIONS; otherwise residue- or trajectory-based REJECT. EARNED therefore dominates historical recurrence, not an explicit unanimous rung rejection. The stronger stamp may never carry the larger backlog: the same cap, boundedness requirement and §6.5 table apply at EARNED and OBLIGATIONS. Residue above five or any unbounded residual prevents both.

### 6.4a Feature-boundary test

A proposed child is a feature, rather than an implementation component, only if all are true:

1. it produces an operator-visible outcome meaningful without its siblings;
2. it has its own failure number rather than merely causing the parent outcome to fail;
3. it can be accepted, released, deferred or rejected without leaving its siblings as an incomplete version of one outcome; and
4. removing sibling implementations still leaves the child's acceptance criteria satisfiable through its declared public inputs and outputs, rather than through an unfinished internal seam.

Every required judge's existing `section-6` coverage evidence begins with exact token `FEATURE_BOUNDARY=SINGLE_FEATURE;` plus one evidence clause of at most 90 characters against the blueprint's stated outcome and failure number when no child set is proposed. This is evidence inside the existing 128-character coverage row, not a new result-schema field. If the author or any judge proposes children, the author publishes one candidate-child matrix with evidence for all four rows and every required judge begins that same coverage cell with `FEATURE_BOUNDARY=MULTI_FEATURE;` or `FEATURE_BOUNDARY=SINGLE_FEATURE;` after scoring the matrix. DECOMPOSE is earned only when all required reports — one at Tier 1, two at Tier 2 — carry `MULTI_FEATURE`; the orchestrator publishes their union and the operator approves the exact finite child set. A Tier 2 disagreement yields `SINGLE_FEATURE` and no child budget. The operator may re-open scope for another counted adjudication, but that later adjudication still requires all required `MULTI_FEATURE` tokens against one matrix before DECOMPOSE.

If all proposed children are required to produce one outcome, they remain components of one blueprint and become ordered prompt packs. Module, process, worker, OAuth, security, persistence, file-custody and test/reality-gate boundaries justify serial packs and explicit interfaces; they do not establish separate features by themselves. Residue count and review history require more detail, not synthetic children.

After REJECT, repair is holistic when budget remains: reconcile every affected section and its inbound and outbound seams, then publish a complete requirement-to-pack matrix naming component ownership, interfaces, dependencies, exact source/test custody, proof and stop conditions. Local finding patches do not qualify. At zero remaining rounds REJECT is terminal; the blueprint stays `[SPEC-DRAFT]` or is separately archived as a historical record, and it does not split merely to reset the budget.

### 6.5 Bounded obligations

An obligation is **bounded** only if it names an owning pack, a named check and a falsifier. The obligations table carries one row per residual finding — register id, grade, blueprint section, unresolved question, what the recon pack must do, owning pack — plus these three clauses verbatim:

> Pack A (recon) MUST resolve each obligation below against LIVE SOURCE and record the resolution with `file:line` evidence, or return `SPEC_INSUFFICIENT` to this blueprint and stop.
> No build pack may close `[FULL]` while any obligation below is open.
> Every DESIGNATED site in this blueprint is converted to VERIFIED by Pack A, or returns `SPEC_INSUFFICIENT`.

This relocates residue to the one place it can be settled — live source, where a guard either exists with a falsifier that fails without it, or it does not.

### 6.6 The guarantee, stated honestly

Every blueprint id consumes at most 8 judged rounds across all adjudications. Decomposition is permitted once only after §6.4a proves a finite child set; children cannot decompose again. **Total judged rounds over a true multi-feature lineage is therefore bounded by 8 × (1 + K), K the approved child count — finite and known before child adjudication begins. A single feature remains bounded at 8.**

func (s *Store) ensureDB() error {
	// Fast path: check if db is already initialized
	if s.db != nil {
		return nil
	}

	// Slow path: initialize database with lock
	s.dbMu.Lock()
	defer s.dbMu.Unlock()

	// Double-check after acquiring lock
	if s.db != nil {
		return nil
	}

	dbPath := s.DBPath
	if dbPath == "" {
		dbPath = defaultDBPath
	}

	// Ensure directory exists
	if err := os.MkdirAll(filepath.Dir(dbPath), 0o755); err != nil {
		return fmt.Errorf("create db directory: %w", err)
	}

	database, err := newDatabase(dbPath)
	if err != nil {
		return fmt.Errorf("open database: %w", err)
	}

	// Generate device ID if needed
	id, err := database.getID()
	if err != nil || id == "" {
		// Generate new UUID for device
		u, err := uuid.NewV7()
		if err == nil {
			database.setID(u.String())
		}
	}

	s.db = database

	// Check if we need to migrate from config.json
	migrated, err := database.isConfigMigrated()
	if err != nil || !migrated {
		if err := s.migrateFromConfig(database); err != nil {
			slog.Warn("failed to migrate from config.json", "error", err)
		}
	}

	// Run one-time migration from legacy airplane_mode behavior.
	if err := s.migrateCloudSetting(database); err != nil {
		return fmt.Errorf("migrate cloud setting: %w", err)
	}

	return nil
}

// migrateCloudSetting migrates legacy airplane_mode into server.json exactly once.
// After this, cloud state is sourced from server.json OR OLLAMA_NO_CLOUD.
func (s *Store) migrateCloudSetting(database *database) error {
	migrated, err := database.isCloudSettingMigrated()
	if err != nil {
		return err
	}
	if migrated {
		return nil
	}

	airplaneMode, err := database.getAirplaneMode()
	if err != nil {
		return err
	}

	if airplaneMode {
		if err := setCloudEnabled(false); err != nil {
			return fmt.Errorf("migrate airplane_mode to cloud disabled: %w", err)
		}
	}

	if err := database.setCloudSettingMigrated(true); err != nil {
		return err
	}

	return nil
}

// migrateFromConfig attempts to migrate ID and FirstTimeRun from config.json
func (s *Store) migrateFromConfig(database *database) error {
	configPath := legacyConfigPath

	// Check if config.json exists
	if _, err := os.Stat(configPath); os.IsNotExist(err) {
		// No config to migrate, mark as migrated
		return database.setConfigMigrated(true)
	}

	// Read the config file
	b, err := os.ReadFile(configPath)
	if err != nil {
		return fmt.Errorf("read legacy config: %w", err)
	}

	var legacy legacyData
	if err := json.Unmarshal(b, &legacy); err != nil {
		// If we can't parse it, just mark as migrated and move on
		slog.Warn("failed to parse legacy config.json", "error", err)
		return database.setConfigMigrated(true)
	}

	// Migrate the ID if present
	if legacy.ID != "" {
		if err := database.setID(legacy.ID); err != nil {
			return fmt.Errorf("migrate device ID: %w", err)
		}
		slog.Info("migrated device ID from config.json")
	}

	hasCompleted := legacy.FirstTimeRun // If old FirstTimeRun is true, it means first run was completed
	if err := database.setHasCompletedFirstRun(hasCompleted); err != nil {
		return fmt.Errorf("migrate first time run: %w", err)
	}
	slog.Info("migrated first run status from config.json", "hasCompleted", hasCompleted)

	// Mark as migrated
	if err := database.setConfigMigrated(true); err != nil {
		return fmt.Errorf("mark config as migrated: %w", err)
	}

	slog.Info("successfully migrated settings from config.json")
	return nil
}

// currentSchemaVersion defines the current database schema version.
// Increment this when making schema changes that require migrations.
const currentSchemaVersion = 17

// database wraps the SQLite connection.
// SQLite handles its own locking for concurrent access:
// - Multiple readers can access the database simultaneously
// - Writers are serialized (only one writer at a time)
// - WAL mode allows readers to not block writers
// This means we don't need application-level locks for database operations.
type database struct {
	conn *sql.DB
}

func newDatabase(dbPath string) (*database, error) {
	// Open database connection
	conn, err := sql.Open("sqlite3", dbPath+"?_foreign_keys=on&_journal_mode=WAL&_busy_timeout=5000&_txlock=immediate")
	if err != nil {
		return nil, fmt.Errorf("open database: %w", err)
	}

	// Test the connection
	if err := conn.Ping(); err != nil {
		conn.Close()
		return nil, fmt.Errorf("ping database: %w", err)
	}

	db := &database{conn: conn}

	// Initialize schema
	if err := db.init(); err != nil {
		conn.Close()
		return nil, fmt.Errorf("initialize database: %w", err)
	}

	return db, nil
}

func (db *database) Close() error {
	_, _ = db.conn.Exec("PRAGMA wal_checkpoint(TRUNCATE);")

	return db.conn.Close()
}

func (db *database) getAllChats() ([]Chat, error) {
	// Query chats with their first user message and latest update time
	query := `
		SELECT 
			c.id, 
			c.title, 
			c.created_at,
			COALESCE(first_msg.content, '') as first_user_content,
			COALESCE(datetime(MAX(m.updated_at)), datetime(c.created_at)) as last_updated
		FROM chats c
		LEFT JOIN (
			SELECT chat_id, content, MIN(id) as min_id
			FROM messages
			WHERE role = 'user'
			GROUP BY chat_id
		) first_msg ON c.id = first_msg.chat_id
		LEFT JOIN messages m ON c.id = m.chat_id
		GROUP BY c.id, c.title, c.created_at, first_msg.content
		ORDER BY last_updated DESC
	`

	rows, err := db.conn.Query(query)
	if err != nil {
		return nil, fmt.Errorf("query chats: %w", err)
	}
	defer rows.Close()

	var chats []Chat
	for rows.Next() {
		var chat Chat
		var createdAt time.Time
		var firstUserContent string
		var lastUpdatedStr string

		err := rows.Scan(
			&chat.ID,
			&chat.Title,
			&createdAt,
			&firstUserContent,
			&lastUpdatedStr,
		)

		// Parse the last updated time
		lastUpdated, _ := time.Parse("2006-01-02 15:04:05", lastUpdatedStr)
		if err != nil {
			return nil, fmt.Errorf("scan chat: %w", err)
		}

		chat.CreatedAt = createdAt

		// Add a dummy first user message for the UI to display
		// This is just for the excerpt, full messages are loaded when needed
		chat.Messages = []Message{}
		if firstUserContent != "" {
			chat.Messages = append(chat.Messages, Message{
				Role:      "user",
				Content:   firstUserContent,
				UpdatedAt: lastUpdated,
			})
		}

		chats = append(chats, chat)
	}

	if err := rows.Err(); err != nil {
		return nil, fmt.Errorf("iterate chats: %w", err)
	}

	return chats, nil
}

func (db *database) getChatWithOptions(id string, loadAttachmentData bool) (*Chat, error) {
	query := `
		SELECT id, title, created_at, browser_state
		FROM chats
		WHERE id = ?
	`

	var chat Chat
	var createdAt time.Time
	var browserState sql.NullString

	err := db.conn.QueryRow(query, id).Scan(
		&chat.ID,
		&chat.Title,
		&createdAt,
		&browserState,
	)
	if err != nil {
		if err == sql.ErrNoRows {
			return nil, fmt.Errorf("chat not found")
		}
		return nil, fmt.Errorf("query chat: %w", err)

		}

	if err != nil {
		return nil, fmt.Errorf("get messages: %w", err)
	}
	chat.Messages = messages

	return &chat, nil
}

func (db *database) saveChat(chat Chat) error {
	tx, err := db.conn.Begin()
	if err != nil {
		return fmt.Errorf("begin transaction: %w", err)
	}
	defer tx.Rollback()

	// Use COALESCE for browser_state to avoid wiping an existing
	// chat-level browser_state when saving a chat that doesn't include a new state payload.
	// Many code paths call SetChat to update metadata/messages only; without COALESCE the
	// UPSERT would overwrite browser_state with NULL, breaking revisit rendering that relies
	// on the last persisted full tool state.
	query := `
		INSERT INTO chats (id, title, created_at, browser_state)
		VALUES (?, ?, ?, ?)
		ON CONFLICT(id) DO UPDATE SET
			title = excluded.title,
			browser_state = COALESCE(excluded.browser_state, chats.browser_state)
	`

	var browserState sql.NullString
	if chat.BrowserState != nil {
		browserState = sql.NullString{String: string(chat.BrowserState), Valid: true}
	}

	_, err = tx.Exec(query,
		chat.ID,
		chat.Title,
		chat.CreatedAt,
		browserState,
	)
	if err != nil {
		return fmt.Errorf("save chat: %w", err)
	}

	// Delete existing messages (we'll re-insert all)
	_, err = tx.Exec("DELETE FROM messages WHERE chat_id = ?", chat.ID)
	if err != nil {
		return fmt.Errorf("delete messages: %w", err)
	}

	// Insert messages
	for _, msg := range chat.Messages {
		messageID, err := db.insertMessage(tx, chat.ID, msg)
		if err != nil {
			return fmt.Errorf("insert message: %w", err)
		}

		// Insert tool calls if any
		for _, toolCall := range msg.ToolCalls {
			err := db.insertToolCall(tx, messageID, toolCall)
			if err != nil {
				return fmt.Errorf("insert tool call: %w", err)
			}
		}
	}

	return tx.Commit()
}

func (db *database) updateLastMessage(chatID string, msg Message) error {
	tx, err := db.conn.Begin()
	if err != nil {
		return fmt.Errorf("begin transaction: %w", err)
	}
	defer tx.Rollback()

	// Get the ID of the last message
	var messageID int64
	err = tx.QueryRow(`
		SELECT MAX(id) FROM messages WHERE chat_id = ?
	`, chatID).Scan(&messageID)
	if err != nil {
		return fmt.Errorf("get last message id: %w", err)
	}

	query := `
		UPDATE messages 
		SET content = ?, thinking = ?, model_name = ?, updated_at = ?, thinking_time_start = ?, thinking_time_end = ?, tool_result = ?
		WHERE id = ?
	`

	var thinkingTimeStart, thinkingTimeEnd sql.NullTime
	if msg.ThinkingTimeStart != nil {
		thinkingTimeStart = sql.NullTime{Time: *msg.ThinkingTimeStart, Valid: true}
	}
	if msg.ThinkingTimeEnd != nil {
		thinkingTimeEnd = sql.NullTime{Time: *msg.ThinkingTimeEnd, Valid: true}
	}

	var modelName sql.NullString
	if msg.Model != "" {
		modelName = sql.NullString{String: msg.Model, Valid: true}
	}

	var toolResultJSON sql.NullString
	if msg.ToolResult != nil {
		resultBytes, err := json.Marshal(msg.ToolResult)
		if err != nil {
			return fmt.Errorf("marshal tool result: %w", err)
		}
		toolResultJSON = sql.NullString{String: string(resultBytes), Valid: true}
	}

	result, err := tx.Exec(query,
		msg.Content,
		msg.Thinking,
		modelName,
		msg.UpdatedAt,
		thinkingTimeStart,
		thinkingTimeEnd,
		toolResultJSON,
		messageID,
	)
	if err != nil {
		return fmt.Errorf("update last message: %w", err)
	}

	rowsAffected, err := result.RowsAffected()
	if err != nil {
		return fmt.Errorf("get rows affected: %w", err)
	}
	if rowsAffected == 0 {
		return fmt.Errorf("no message found to update")
	}

	_, err = tx.Exec("DELETE FROM attachments WHERE message_id = ?", messageID)
	if err != nil {
		return fmt.Errorf("delete existing attachments: %w", err)
	}
	for _, att := range msg.Attachments {
		err := db.insertAttachment(tx, messageID, att)
		if err != nil {
			return fmt.Errorf("insert attachment: %w", err)
		}
	}

	_, err = tx.Exec("DELETE FROM tool_calls WHERE message_id = ?", messageID)
	if err != nil {
		return fmt.Errorf("delete existing tool calls: %w", err)
	}
	for _, toolCall := range msg.ToolCalls {
		err := db.insertToolCall(tx, messageID, toolCall)
		if err != nil {
			return fmt.Errorf("insert tool call: %w", err)
		}
	}

	return tx.Commit()
}

func (db *database) getMessages(chatID string, loadAttachmentData bool) ([]Message, error) {
	query := `
		SELECT id, role, content, thinking, stream, model_name, created_at, updated_at, thinking_time_start, thinking_time_end, tool_result
		FROM messages
		WHERE chat_id = ?
		ORDER BY id ASC
	`

	rows, err := db.conn.Query(query, chatID)
	if err != nil {
		return nil, fmt.Errorf("query messages: %w", err)
	}
	defer rows.Close()

	var messages []Message
	for rows.Next() {
		var msg Message
		var messageID int64
		var thinkingTimeStart, thinkingTimeEnd sql.NullTime
		var modelName sql.NullString
		var toolResult sql.NullString

		err := rows.Scan(
			&messageID,
			&msg.Role,
			&msg.Content,
			&msg.Thinking,
			&msg.Stream,
			&modelName,
			&msg.CreatedAt,
			&msg.UpdatedAt,
			&thinkingTimeStart,
			&thinkingTimeEnd,
			&toolResult,
		)
		if err != nil {
			return nil, fmt.Errorf("scan message: %w", err)
		}

		attachments, err := db.getAttachments(messageID, loadAttachmentData)
		if err != nil {
			return nil, fmt.Errorf("get attachments: %w", err)
		}
		msg.Attachments = attachments

		if thinkingTimeStart.Valid {
			msg.ThinkingTimeStart = &thinkingTimeStart.Time
		}
		if thinkingTimeEnd.Valid {
			msg.ThinkingTimeEnd = &thinkingTimeEnd.Time
		}

		// Parse tool result from JSON if present
		if toolResult.Valid && toolResult.String != "" {
			var result json.RawMessage
			if err := json.Unmarshal([]byte(toolResult.String), &result); err == nil {
				msg.ToolResult = &result
			}
		}

		// Set model if present
		if modelName.Valid && modelName.String != "" {
			msg.Model = modelName.String
		}

		// Get tool calls for this message
		toolCalls, err := db.getToolCalls(messageID)
		if err != nil {
			return nil, fmt.Errorf("get tool calls: %w", err)
		}
		msg.ToolCalls = toolCalls

		messages = append(messages, msg)
	}

	if err := rows.Err(); err != nil {
		return nil, fmt.Errorf("iterate messages: %w", err)
	}

	return messages, nil
}

func (db *database) insertMessage(tx *sql.Tx, chatID string, msg Message) (int64, error) {
	query := `
		INSERT INTO messages (chat_id, role, content, thinking, stream, model_name, created_at, updated_at, thinking_time_start, thinking_time_end, tool_result)
		VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?)
	`

	var thinkingTimeStart, thinkingTimeEnd sql.NullTime
	if msg.ThinkingTimeStart != nil {
		thinkingTimeStart = sql.NullTime{Time: *msg.ThinkingTimeStart, Valid: true}
	}
	if msg.ThinkingTimeEnd != nil {
		thinkingTimeEnd = sql.NullTime{Time: *msg.ThinkingTimeEnd, Valid: true}
	}

	var modelName sql.NullString
	if msg.Model != "" {
		modelName = sql.NullString{String: msg.Model, Valid: true}
	}

	var toolResultJSON sql.NullString
	if msg.ToolResult != nil {
		resultBytes, err := json.Marshal(msg.ToolResult)
		if err != nil {
			return 0, fmt.Errorf("marshal tool result: %w", err)
		}
		toolResultJSON = sql.NullString{String: string(resultBytes), Valid: true}
	}

	result, err := tx.Exec(query,
		chatID,
		msg.Role,
		msg.Content,
		msg.Thinking,
		msg.Stream,
		modelName,
		msg.CreatedAt,
		msg.UpdatedAt,

		thinkingTimeEnd,
		toolResultJSON,

		return 0, err
	}

	messageID, err := result.LastInsertId()

		return 0, err
	}

	for _, att := range msg.Attachments {
		err := db.insertAttachment(tx, messageID, att)
		if err != nil {

		}

func (db *database) getToolCalls(messageID int64) ([]ToolCall, error) {

		return nil, fmt.Errorf("query tool calls: %w", err)
	}
	defer rows.Close()

	var toolCalls []ToolCall
	for rows.Next() {
		var tc ToolCall
		var functionResult sql.NullString

		err := rows.Scan(
			&tc.Type,
			&tc.Function.Name,
			&tc.Function.Arguments,
			&functionResult,
		)
		if err != nil {
			return nil, fmt.Errorf("scan tool call: %w", err)
		}

		if functionResult.Valid && functionResult.String != "" {
			// Parse the JSON result
			var result json.RawMessage
			if err := json.Unmarshal([]byte(functionResult.String), &result); err == nil {
				tc.Function.Result = &result
			}
		}

		toolCalls = append(toolCalls, tc)
	}

	if err := rows.Err(); err != nil {
		return nil, fmt.Errorf("iterate tool calls: %w", err)
	}

	return toolCalls, nil

		messageID,
		tc.Type,
		tc.Function.Name,
		tc.Function.Arguments,
		functionResult,
	)
	return err
}

// ollamaProxy creates a reverse proxy handler to the Ollama server
func (s *Server) ollamaProxy() http.Handler {
	var (
		proxy   http.Handler
		proxyMu sync.Mutex
	)

	return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		proxyMu.Lock()
		p := proxy
		proxyMu.Unlock()

		if p == nil {
			proxyMu.Lock()
			if proxy == nil {
				var err error
				for i := range 2 {
					if i > 0 {
						s.log().Warn("ollama server not ready, retrying", "attempt", i+1)
						time.Sleep(1 * time.Second)
					}

					err = WaitForServer(context.Background(), 10*time.Second)
					if err == nil {
						break
					}
				}

				if err != nil {
					proxyMu.Unlock()
					s.log().Error("ollama server not ready after retries", "error", err)
					http.Error(w, "Ollama server is not ready", http.StatusServiceUnavailable)
					return
				}

				target := envconfig.ConnectableHost()
				s.log().Info("configuring ollama proxy", "target", target.String())

				newProxy := httputil.NewSingleHostReverseProxy(target)

				originalDirector := newProxy.Director
				newProxy.Director = func(req *http.Request) {
					originalDirector(req)
					req.Host = target.Host
					s.log().Debug("proxying request", "method", req.Method, "path", req.URL.Path, "target", target.Host)
				}

				newProxy.ErrorHandler = func(w http.ResponseWriter, r *http.Request, err error) {
					s.log().Error("proxy error", "error", err, "path", r.URL.Path, "target", target.String())
					http.Error(w, "proxy error: "+err.Error(), http.StatusBadGateway)
				}

				proxy = newProxy
				p = newProxy
			} else {
				p = proxy
			}
			proxyMu.Unlock()
		}

		p.ServeHTTP(w, r)
	})
}

// doSelfSigned sends a self-signed request to the ollama.com API
func (s *Server) doSelfSigned(ctx context.Context, method, path string) (*http.Response, error) {
	timestamp := strconv.FormatInt(time.Now().Unix(), 10)
	// Form the string to sign: METHOD,PATH?ts=TIMESTAMP
	signString := fmt.Sprintf("%s,%s?ts=%s", method, path, timestamp)
	signature, err := ollamaAuth.Sign(ctx, []byte(signString))
	if err != nil {
		return nil, fmt.Errorf("failed to sign request: %w", err)
	}

	endpoint := fmt.Sprintf("%s%s?ts=%s", OllamaDotCom, path, timestamp)
	req, err := http.NewRequestWithContext(ctx, method, endpoint, nil)
	if err != nil {
		return nil, fmt.Errorf("failed to create request: %w", err)
	}
	req.Header.Set("Authorization", fmt.Sprintf("Bearer %s", signature))

	return s.httpClient().Do(req)
}

// WaitForServer waits for the Ollama server to be ready
func WaitForServer(ctx context.Context, timeout time.Duration) error {
	deadline := time.Now().Add(timeout)
	for time.Now().Before(deadline) {
		c, err := api.ClientFromEnvironment()
		if err != nil {
			return err
		}
		if _, err := c.Version(ctx); err == nil {
			slog.Debug("ollama server is ready")
			return nil
		}
		time.Sleep(10 * time.Millisecond)
	}
	return errors.New("timeout waiting for Ollama server to be ready")
}

// checkModelUpstream makes a HEAD request to the Ollama registry to get the upstream digest and push time
func (s *Server) checkModelUpstream(ctx context.Context, modelName string, timeout time.Duration) (string, int64, error) {
	// Create a context with timeout for the registry check
	checkCtx, cancel := context.WithTimeout(ctx, timeout)
	defer cancel()

	// Parse model name to get namespace, model, and tag
	parts := strings.Split(modelName, ":")
	name := parts[0]
	tag := "latest"
	if len(parts) > 1 {
		tag = parts[1]
	}

	if !strings.Contains(name, "/") {
		// If the model name does not contain a slash, assume it's a library model
		name = "library/" + name
	}

	// Check the model in the Ollama registry using HEAD request
	url := OllamaDotCom + "/v2/" + name + "/manifests/" + tag
	req, err := http.NewRequestWithContext(checkCtx, "HEAD", url, nil)
	if err != nil {
		return "", 0, err
	}

	httpClient := s.httpClient()
	httpClient.Timeout = timeout

	resp, err := httpClient.Do(req)
	if err != nil {
		return "", 0, err
	}
	defer resp.Body.Close()

	if resp.StatusCode != http.StatusOK {
		return "", 0, fmt.Errorf("registry returned status %d", resp.StatusCode)
	}

	digest := resp.Header.Get("ollama-content-digest")
	if digest == "" {
		return "", 0, fmt.Errorf("no digest header found")
	}

	var pushTime int64
	if pushTimeStr := resp.Header.Get("ollama-push-time"); pushTimeStr != "" {
		if pt, err := strconv.ParseInt(pushTimeStr, 10, 64); err == nil {
			pushTime = pt
		}
	}

	return digest, pushTime, nil
}

// isNetworkError checks if an error string contains common network/connection error patterns
func isNetworkError(errStr string) bool {
	networkErrorPatterns := []string{
		"connection refused",
		"no such host",
		"timeout",
		"network is unreachable",
		"connection reset",
		"connection timed out",
		"temporary failure",
		"dial tcp",
		"i/o timeout",
		"context deadline exceeded",
		"broken pipe",
	}

	for _, pattern := range networkErrorPatterns {
		if strings.Contains(errStr, pattern) {
			return true
		}
	}
	return false
}

		return responses.ErrorEvent{
			EventName: "error",
			Error:     "Could not verify you are signed in. Please sign in and try again.",
			Code:      "cloud_unauthorized",
		}
	}

	errStr := err.Error()

	switch {
	case strings.Contains(errStr, "402"):
		return responses.ErrorEvent{
			EventName: "error",
			Error:     "You've reached your usage limit, please upgrade to continue",
			Code:      "usage_limit_upgrade",
		}
	case strings.HasPrefix(errStr, "pull model manifest") && isNetworkError(errStr):
		return responses.ErrorEvent{
			EventName: "error",
			Error:     "Unable to download model. Please check your internet connection to download the model for offline use.",
			Code:      "offline_download_error",
		}
	case errors.Is(err, ErrNetworkOffline) || strings.Contains(errStr, "operation timed out"):
		return responses.ErrorEvent{
			EventName: "error",
			Error:     "Connection lost",
			Code:      "turbo_connection_lost",
		}
	}
	return responses.ErrorEvent{
		EventName: "error",
		Error:     err.Error(),
	}
}

func userMessageText(messages []store.Message) string {
	var b strings.Builder
	for _, message := range messages {
		if message.Role != "user" {
			continue
		}
		b.WriteString(message.Content)
		b.WriteByte('\n')
	}
	return b.String()
}

func (s *Server) browserState(chat *store.Chat) (*responses.BrowserStateData, bool) {
	if len(chat.BrowserState) > 0 {
		var st responses.BrowserStateData
		if err := json.Unmarshal(chat.BrowserState, &st); err == nil {
			return &st, true
		}
	}
	return nil, false
}

// reconstructBrowserState (legacy): return the latest full browser state stored in messages.
func reconstructBrowserState(messages []store.Message, defaultViewTokens int) *responses.BrowserStateData {
	for i := len(messages) - 1; i >= 0; i-- {
		msg := messages[i]
		if msg.ToolResult == nil {
			continue
		}
		var st responses.BrowserStateData
		if err := json.Unmarshal(*msg.ToolResult, &st); err == nil {
			if len(st.PageStack) > 0 || len(st.URLToPage) > 0 {
				if st.ViewTokens == 0 {
					st.ViewTokens = defaultViewTokens
				}
				return &st
			}
		}
	}
	return nil
}

func (s *Server) chat(w http.ResponseWriter, r *http.Request) error {
	w.Header().Set("Content-Type", "text/jsonl")
	w.Header().Set("Cache-Control", "no-cache")
	w.Header().Set("Connection", "keep-alive")
	w.Header().Set("Transfer-Encoding", "chunked")

	flusher, ok := w.(http.Flusher)
	if !ok {
		return errors.New("streaming not supported")
	}

	if r.Method != "POST" {
		return not.Found
	}

	cid := r.PathValue("id")
	createdChat := false

	// if cid is the literal string "new", then we create a new chat before
	// performing our normal actions
	if cid == "new" {
		u, err := uuid.NewV7()
		if err != nil {
			return fmt.Errorf("failed to generate new chat id: %w", err)
		}
		cid = u.String()
		createdChat = true
	}

	var req responses.ChatRequest
	if err := json.NewDecoder(r.Body).Decode(&req); err != nil {
		fmt.Fprintf(os.Stderr, "error unmarshalling body: %v\n", err)
		return fmt.Errorf("invalid request body: %w", err)
	}

	if req.Model == "" {
		return fmt.Errorf("empty model")
	}

	// Don't allow empty messages unless forceUpdate is true
	if req.Prompt == "" && !req.ForceUpdate {
		return fmt.Errorf("empty message")
	}

	if createdChat {
		// send message to the client that the chat has been created
		json.NewEncoder(w).Encode(responses.ChatEvent{
			EventName: "chat_created",
			ChatID:    &cid,
		})
		flusher.Flush()
	}

	// Check if this is from a specific message index (e.g. for editing)
	idx := -1
	if req.Index != nil {
		idx = *req.Index
	}

	// Load chat with attachments since we need them for processing
	chat, err := s.Store.ChatWithOptions(cid, true)
	if err != nil {
		if !errors.Is(err, not.Found) {
			return err
		}
		chat = store.NewChat(cid)
	}

	// Only add user message if not forceUpdate
	if !req.ForceUpdate {
		var messageOptions *store.MessageOptions
		if len(req.Attachments) > 0 {
			storeAttachments := make([]store.File, 0, len(req.Attachments))

			for _, att := range req.Attachments {
				if att.Data == "" {
					// This is an existing file reference - keep it from the original message
					if idx >= 0 && idx < len(chat.Messages) {
						originalMessage := chat.Messages[idx]
						// Find the file by filename in the original message
						for _, originalFile := range originalMessage.Attachments {
							if originalFile.Filename == att.Filename {
								storeAttachments = append(storeAttachments, originalFile)
								break
							}
						}
					}
				} else {
					// This is a new file - decode base64 data
					data, err := base64.StdEncoding.DecodeString(att.Data)
					if err != nil {
						s.log().Error("failed to decode attachment data", "error", err, "filename", att.Filename)
						continue
					}

					storeAttachments = append(storeAttachments, store.File{
						Filename: att.Filename,
						Data:     data,
					})
				}
			}

			messageOptions = &store.MessageOptions{
				Attachments: storeAttachments,
			}
		}
		userMsg := store.NewMessage("user", req.Prompt, messageOptions)

		if idx >= 0 && idx < len(chat.Messages) {
			// Generate from specified message: truncate and replace
			chat.Messages = chat.Messages[:idx]
			chat.Messages = append(chat.Messages, userMsg)
		} else {
			// Normal mode: append new message
			chat.Messages = append(chat.Messages, userMsg)
		}

		if err := s.Store.SetChat(*chat); err != nil {
			return err
		}
	}

	ctx, cancel := context.WithCancel(r.Context())
	defer cancel()

	_, cancelLoading := context.WithCancel(ctx)
	loading := false

	c := s.inferenceClient()

	// Check if the model exists locally by trying to show it
	// TODO (jmorganca): skip this round trip and instead just act
	// on a 404 error on chat
	_, err = c.Show(ctx, &api.ShowRequest{Model: req.Model})
	if err != nil || req.ForceUpdate {
		// Create an empty assistant message to store the model information
		// This will be overwritten when the model responds
		chat.Messages = append(chat.Messages, store.NewMessage("assistant", "", &store.MessageOptions{Model: req.Model}))
		if err := s.Store.SetChat(*chat); err != nil {
			cancelLoading()
			return err
		}
		// Send download progress events while the model is being pulled
		// TODO (jmorganca): this only shows the largest digest, but we
		// should show the progress for the total size of the download
		var largestDigest string
		var largestTotal int64

		err = c.Pull(ctx, &api.PullRequest{Model: req.Model}, func(progress api.ProgressResponse) error {
			if progress.Digest != "" && progress.Total > largestTotal {
				largestDigest = progress.Digest
				largestTotal = progress.Total
			}

			if progress.Digest != "" && progress.Digest == largestDigest {
				progressEvent := responses.DownloadEvent{
					EventName: string(EventDownload),
					Total:     progress.Total,
					Completed: progress.Completed,
					Done:      false,
				}

				if err := json.NewEncoder(w).Encode(progressEvent); err != nil {
					return err
				}
				flusher.Flush()
			}
			return nil
		})
		if err != nil {
			s.log().Error("model download error", "error", err, "model", req.Model)
			errorEvent := s.getError(err)
			json.NewEncoder(w).Encode(errorEvent)
			flusher.Flush()
			cancelLoading()
			return fmt.Errorf("failed to download model: %w", err)
		}

		if err := json.NewEncoder(w).Encode(responses.DownloadEvent{
			EventName: string(EventDownload),
			Completed: largestTotal,
			Total:     largestTotal,
			Done:      true,
		}); err != nil {
			cancelLoading()
			return err
		}
		flusher.Flush()

		// If forceUpdate, we're done after updating the model
		if req.ForceUpdate {
			json.NewEncoder(w).Encode(responses.ChatEvent{EventName: "done"})
			flusher.Flush()
			cancelLoading()
			return nil
		}
	}

	loading = true
	defer cancelLoading()

	// Check the model capabilities
	details, err := c.Show(ctx, &api.ShowRequest{Model: req.Model})

	if err != nil || details == nil {
		errorEvent := s.getError(err)
		json.NewEncoder(w).Encode(errorEvent)
		flusher.Flush()
		s.log().Error("failed to show model details", "error", err, "model", req.Model)
		return nil
	}
	think := slices.Contains(details.Capabilities, model.CapabilityThinking)

	var thinkValue any

	if req.Think != nil {
		thinkValue = req.Think
	} else {
		thinkValue = think
	}

	// Check if the last user message has attachments
	// TODO (parthsareen): this logic will change with directory drag and drop
	hasAttachments := false
	if len(chat.Messages) > 0 {
		lastMsg := chat.Messages[len(chat.Messages)-1]
		if lastMsg.Role == "user" && len(lastMsg.Attachments) > 0 {
			hasAttachments = true
		}
	}

	// Check if agent or tools mode is enabled
	// Note: Skip agent/tools mode if user has attachments, as the agent doesn't handle file attachments properly
	registry := tools.NewRegistry()
	// What the connected MCP servers say about themselves, for the system
	// prompt. Empty unless a server both connected and had something to say.
	var mcpInstructions string
	var browser *tools.Browser
	ctx = tools.WithAllowedDirectURLs(ctx, userMessageText(chat.Messages))

	if !hasAttachments {
		WebSearchEnabled := req.WebSearch != nil && *req.WebSearch
		hasToolsCapability := slices.Contains(details.Capabilities, model.CapabilityTools)

		if WebSearchEnabled && hasToolsCapability {
			if supportsBrowserTools(req.Model) {
				browserState, ok := s.browserState(chat)
				if !ok {
					browserState = reconstructBrowserState(chat.Messages, tools.DefaultViewTokens)
				}
				browser = tools.NewBrowser(browserState)
				registry.Register(tools.NewBrowserSearch(browser))
				registry.Register(tools.NewBrowserOpen(browser))
				registry.Register(tools.NewBrowserFind(browser))
			} else {
				registry.Register(&tools.WebSearch{})
				registry.Register(&tools.WebFetch{})
			}
		}

		if hasToolsCapability {
			s.registerMCPTools(registry)
			mcpInstructions = s.mcpInstructions()
		}
	}

	var thinkingTimeStart *time.Time = nil
	var thinkingTimeEnd *time.Time = nil
	// Request-only assistant tool_calls buffer
	// if tool_calls arrive before any assistant text, we keep them here,
	// inject them into the next request, and attach on first assistant content/thinking.
	var pendingAssistantToolCalls []store.ToolCall

	passNum := 1

	for {
		var toolsExecuted bool

		availableTools := registry.OllamaTools()

		// If we have pending assistant tool_calls and no assistant yet,
		// build the request against a temporary chat that includes a
		// request-only assistant with tool_calls inserted BEFORE tool messages
		reqChat := chat
		if len(pendingAssistantToolCalls) > 0 {
			if len(chat.Messages) == 0 || chat.Messages[len(chat.Messages)-1].Role != "assistant" {
				temp := *chat
				synth := store.NewMessage("assistant", "", &store.MessageOptions{Model: req.Model, ToolCalls: pendingAssistantToolCalls})
				insertIdx := len(temp.Messages) - 1
				for insertIdx >= 0 && temp.Messages[insertIdx].Role == "tool" {
					insertIdx--
				}
				if insertIdx < 0 {
					temp.Messages = append([]store.Message{synth}, temp.Messages...)
				} else {
					tmp := make([]store.Message, 0, len(temp.Messages)+1)
					tmp = append(tmp, temp.Messages[:insertIdx+1]...)
					tmp = append(tmp, synth)
					tmp = append(tmp, temp.Messages[insertIdx+1:]...)
					temp.Messages = tmp
				}

				reqChat = &temp
			}
		}
		chatReq, err := s.buildChatRequest(reqChat, req.Model, thinkValue, availableTools, mcpInstructions)
		if err != nil {
			return err
		}

		err = c.Chat(ctx, chatReq, func(res api.ChatResponse) error {
			if loading {
				// Remove the loading indicator on first token
				cancelLoading()
				loading = false
			}

			// Start thinking timer on first thinking content or after tool call when thinking again
			if res.Message.Thinking != "" && (thinkingTimeStart == nil || thinkingTimeEnd != nil) {
				now := time.Now()
				thinkingTimeStart = &now
				thinkingTimeEnd = nil
			}

			if res.Message.Content == "" && res.Message.Thinking == "" && len(res.Message.ToolCalls) == 0 {
				return nil
			}

			event := EventChat
			if thinkingTimeStart != nil && res.Message.Content == "" && len(res.Message.ToolCalls) == 0 {
				event = EventThinking
			}

			if len(res.Message.ToolCalls) > 0 {
				event = EventToolCall
			}

			if event == EventToolCall && thinkingTimeStart != nil && thinkingTimeEnd == nil {
				now := time.Now()
				thinkingTimeEnd = &now
			}

			if event == EventChat && thinkingTimeStart != nil && thinkingTimeEnd == nil && res.Message.Content != "" {
				now := time.Now()
				thinkingTimeEnd = &now
			}

			json.NewEncoder(w).Encode(chatEventFromApiChatResponse(res, thinkingTimeStart, thinkingTimeEnd))
			flusher.Flush()

			switch event {
			case EventToolCall:
				if thinkingTimeEnd != nil {
					if len(chat.Messages) > 0 && chat.Messages[len(chat.Messages)-1].Role == "assistant" {
						lastMsg := &chat.Messages[len(chat.Messages)-1]
						lastMsg.ThinkingTimeEnd = thinkingTimeEnd
						lastMsg.UpdatedAt = time.Now()
						s.Store.UpdateLastMessage(chat.ID, *lastMsg)
					}
					thinkingTimeStart = nil
					thinkingTimeEnd = nil
				}

				// attach tool_calls to an existing assistant if present,
				// otherwise (for standalone web_search/web_fetch) buffer for request-only injection.
				if len(res.Message.ToolCalls) > 0 {
					if len(chat.Messages) > 0 && chat.Messages[len(chat.Messages)-1].Role == "assistant" {
						toolCalls := make([]store.ToolCall, len(res.Message.ToolCalls))
						for i, tc := range res.Message.ToolCalls {
							argsJSON, _ := json.Marshal(tc.Function.Arguments)
							toolCalls[i] = store.ToolCall{
								Type: "function",
								Function: store.ToolFunction{
									Name:      tc.Function.Name,
									Arguments: string(argsJSON),
								},
							}
						}
						lastMsg := &chat.Messages[len(chat.Messages)-1]
						lastMsg.ToolCalls = toolCalls
						if err := s.Store.UpdateLastMessage(chat.ID, *lastMsg); err != nil {
							return err
						}
					} else {
						onlyStandalone := true
						for _, tc := range res.Message.ToolCalls {
							if !(tc.Function.Name == "web_search" || tc.Function.Name == "web_fetch") {
								onlyStandalone = false
								break
							}
						}
						if onlyStandalone {
							toolCalls := make([]store.ToolCall, len(res.Message.ToolCalls))
							for i, tc := range res.Message.ToolCalls {
								argsJSON, _ := json.Marshal(tc.Function.Arguments)
								toolCalls[i] = store.ToolCall{
									Type: "function",
									Function: store.ToolFunction{
										Name:      tc.Function.Name,
										Arguments: string(argsJSON),
									},
								}
							}

							synth := store.NewMessage("assistant", "", &store.MessageOptions{Model: req.Model, ToolCalls: toolCalls})
							chat.Messages = append(chat.Messages, synth)
							if err := s.Store.AppendMessage(chat.ID, synth); err != nil {
								return err
							}

							// clear buffer to avoid-injecting again
							pendingAssistantToolCalls = nil
						}
					}
				}

				for _, toolCall := range res.Message.ToolCalls {
					// continues loop as tools were executed
					toolsExecuted = true
					args := toolCall.Function.Arguments.ToMap()

					// Ask before running anything that requires it. This blocks
					// the streaming response until the answer arrives on a
					// separate request, so a refusal is the only outcome that
					// costs nothing.
					if err := s.awaitToolApproval(ctx, w, flusher, chat.ID, registry, toolCall.Function.Name, args); err != nil {
						errContent := fmt.Sprintf("Error: %v", err)
						toolErrMsg := store.NewMessage("tool", errContent, nil)
						toolErrMsg.ToolName = toolCall.Function.Name
						chat.Messages = append(chat.Messages, toolErrMsg)
						if appendErr := s.Store.AppendMessage(chat.ID, toolErrMsg); appendErr != nil {
							return appendErr
						}
						toolResult := true
						json.NewEncoder(w).Encode(responses.ChatEvent{
							EventName: "tool",
							Content:   &errContent,
							ToolName:  &toolCall.Function.Name,
						})
						flusher.Flush()
						json.NewEncoder(w).Encode(responses.ChatEvent{
							EventName:  "tool_result",
							Content:    &errContent,
							ToolName:   &toolCall.Function.Name,
							ToolResult: &toolResult,
						})
						flusher.Flush()
						continue
					}

					result, content, err := registry.Execute(ctx, toolCall.Function.Name, args)
					if err != nil {
						errContent := fmt.Sprintf("Error: %v", err)
						toolErrMsg := store.NewMessage("tool", errContent, nil)
						toolErrMsg.ToolName = toolCall.Function.Name
						chat.Messages = append(chat.Messages, toolErrMsg)
						if err := s.Store.AppendMessage(chat.ID, toolErrMsg); err != nil {
							return err
						}

						// Emit tool error event
						toolResult := true
						json.NewEncoder(w).Encode(responses.ChatEvent{
							EventName: "tool",
							Content:   &errContent,
							ToolName:  &toolCall.Function.Name,
						})
						flusher.Flush()

						json.NewEncoder(w).Encode(responses.ChatEvent{
							EventName:      "tool_result",
							Content:        &errContent,
							ToolName:       &toolCall.Function.Name,
							ToolResult:     &toolResult,
							ToolResultData: nil, // No result data for errors
						})
						flusher.Flush()
						continue
					}

					var tr json.RawMessage
					if strings.HasPrefix(toolCall.Function.Name, "browser.search") {
						// For standalone web_search, ensure the tool message has readable content
						// so the second-pass model can consume results, while keeping browser state flow intact.
						// We still persist tool msg with content below.
						// (No browser state update needed for standalone.)
					} else if strings.HasPrefix(toolCall.Function.Name, "browser") {
						stateBytes, err := json.Marshal(browser.State())
						if err != nil {
							return fmt.Errorf("failed to marshal browser state: %w", err)
						}
						if err := s.Store.UpdateChatBrowserState(chat.ID, json.RawMessage(stateBytes)); err != nil {
							return fmt.Errorf("failed to persist browser state to chat: %w", err)
						}
						// tool result is not added to the tool message for the browser tool
					} else {
						var err error
						tr, err = json.Marshal(result)
						if err != nil {
							return fmt.Errorf("failed to marshal tool result: %w", err)
						}
					}
					// ensure tool message sent back to the model has content (if empty, use a sensible fallback)
					modelContent := content
					if toolCall.Function.Name == "web_fetch" && modelContent == "" {
						if str, ok := result.(string); ok {
							modelContent = str
						}
					}
					if modelContent == "" && len(tr) > 0 {
						s.log().Debug("tool message empty, sending json result")
						modelContent = string(tr)
					}
					toolMsg := store.NewMessage("tool", modelContent, &store.MessageOptions{
						ToolResult: &tr,
					})
					toolMsg.ToolName = toolCall.Function.Name
					chat.Messages = append(chat.Messages, toolMsg)

					s.Store.AppendMessage(chat.ID, toolMsg)

					// Emit tool message event (matching agent pattern)
					toolResult := true
					json.NewEncoder(w).Encode(responses.ChatEvent{
						EventName: "tool",
						Content:   &content,
						ToolName:  &toolCall.Function.Name,
					})
					flusher.Flush()

					var toolState any = nil
					if browser != nil {
						toolState = browser.State()
					}
					// Stream tool result to frontend

					json.NewEncoder(w).Encode(responses.ChatEvent{
						EventName:      "tool_result",
						Content:        &content,
						ToolName:       &toolCall.Function.Name,
						ToolResult:     &toolResult,
						ToolResultData: result,
						ToolState:      toolState,
					})
					flusher.Flush()
				}

			case EventChat:
				// Append the new message to the chat history
				if len(chat.Messages) == 0 || chat.Messages[len(chat.Messages)-1].Role != "assistant" {
					newMsg := store.NewMessage("assistant", "", &store.MessageOptions{Model: req.Model})
					chat.Messages = append(chat.Messages, newMsg)
					// Append new message to database
					if err := s.Store.AppendMessage(chat.ID, newMsg); err != nil {
						return err
					}
					// Attach any buffered tool_calls (request-only) now that assistant has started
					if len(pendingAssistantToolCalls) > 0 {
						lastMsg := &chat.Messages[len(chat.Messages)-1]
						lastMsg.ToolCalls = pendingAssistantToolCalls

						pendingAssistantToolCalls = nil
						if err := s.Store.UpdateLastMessage(chat.ID, *lastMsg); err != nil {
							return err
						}
					}
				}

				// Append token to last assistant message & persist
				lastMsg := &chat.Messages[len(chat.Messages)-1]
				lastMsg.Content += res.Message.Content
				lastMsg.UpdatedAt = time.Now()
				// Update thinking time fields
				if thinkingTimeStart != nil {
					lastMsg.ThinkingTimeStart = thinkingTimeStart
				}
				if thinkingTimeEnd != nil {
					lastMsg.ThinkingTimeEnd = thinkingTimeEnd
				}
				// Use optimized update for streaming
				if err := s.Store.UpdateLastMessage(chat.ID, *lastMsg); err != nil {
					return err
				}
			case EventThinking:
				// Persist thinking content
				if len(chat.Messages) == 0 || chat.Messages[len(chat.Messages)-1].Role != "assistant" {
					newMsg := store.NewMessage("assistant", "", &store.MessageOptions{
						Model:    req.Model,
						Thinking: res.Message.Thinking,
					})
					chat.Messages = append(chat.Messages, newMsg)
					// Append new message to database
					if err := s.Store.AppendMessage(chat.ID, newMsg); err != nil {
						return err
					}
					// Attach any buffered tool_calls now that assistant exists
					if len(pendingAssistantToolCalls) > 0 {
						lastMsg := &chat.Messages[len(chat.Messages)-1]
						lastMsg.ToolCalls = pendingAssistantToolCalls

						pendingAssistantToolCalls = nil
						if err := s.Store.UpdateLastMessage(chat.ID, *lastMsg); err != nil {
							return err
						}
					}
				} else {
					// Update thinking content of existing message
					lastMsg := &chat.Messages[len(chat.Messages)-1]
					lastMsg.Thinking += res.Message.Thinking
					lastMsg.UpdatedAt = time.Now()
					// Update thinking time fields
					if thinkingTimeStart != nil {
						lastMsg.ThinkingTimeStart = thinkingTimeStart
					}
					if thinkingTimeEnd != nil {
						lastMsg.ThinkingTimeEnd = thinkingTimeEnd
					}

					// Use optimized update for streaming
					if err := s.Store.UpdateLastMessage(chat.ID, *lastMsg); err != nil {
						return err
					}
				}
			}
			return nil
		})
		if err != nil {
			s.log().Error("chat stream error", "error", err)
			errorEvent := s.getError(err)
			json.NewEncoder(w).Encode(errorEvent)
			flusher.Flush()
			return nil
		}

		// If no tools were executed, exit the loop
		if !toolsExecuted {
			break
		}

		passNum++
	}

	// handle cases where thinking started but didn't finish
	// this can happen if the client disconnects or the request is cancelled
	// TODO (jmorganca): this should be merged with code above
	if thinkingTimeStart != nil && thinkingTimeEnd == nil {
		now := time.Now()
		thinkingTimeEnd = &now
		if len(chat.Messages) > 0 && chat.Messages[len(chat.Messages)-1].Role == "assistant" {
			lastMsg := &chat.Messages[len(chat.Messages)-1]
			lastMsg.ThinkingTimeEnd = thinkingTimeEnd
			lastMsg.UpdatedAt = time.Now()
			s.Store.UpdateLastMessage(chat.ID, *lastMsg)
		}
	}

	json.NewEncoder(w).Encode(responses.ChatEvent{EventName: "done"})
	flusher.Flush()

	if len(chat.Messages) > 0 {
		chat.Messages[len(chat.Messages)-1].Stream = false
	}
	return s.Store.SetChat(*chat)
}

func (s *Server) getChat(w http.ResponseWriter, r *http.Request) error {
	cid := r.PathValue("id")

	if cid == "" {
		return fmt.Errorf("chat ID is required")
	}

	chat, err := s.Store.Chat(cid)
	if err != nil {
		// Return empty chat if not found
		data := responses.ChatResponse{
			Chat: store.Chat{},
		}
		w.Header().Set("Content-Type", "application/json")
		json.NewEncoder(w).Encode(data)
		return nil //nolint:nilerr
	}

	// fill missing tool_name on tool messages (from previous tool_calls) so labels don’t flip after reload.
	if chat != nil && len(chat.Messages) > 0 {
		for i := range chat.Messages {
			if chat.Messages[i].Role == "tool" && chat.Messages[i].ToolName == "" && chat.Messages[i].ToolResult != nil {
				for j := i - 1; j >= 0; j-- {
					if chat.Messages[j].Role == "assistant" && len(chat.Messages[j].ToolCalls) > 0 {
						last := chat.Messages[j].ToolCalls[len(chat.Messages[j].ToolCalls)-1]
						if last.Function.Name != "" {
							chat.Messages[i].ToolName = last.Function.Name
						}
						break
					}
				}
			}
		}
	}

	browserState, ok := s.browserState(chat)
	if !ok {
		browserState = reconstructBrowserState(chat.Messages, tools.DefaultViewTokens)
	}
	// clear the text and lines of all pages as it is not needed for rendering
	if browserState != nil {
		for _, page := range browserState.URLToPage {
			page.Lines = nil
			page.Text = ""
		}

		if cleanedState, err := json.Marshal(browserState); err == nil {
			chat.BrowserState = json.RawMessage(cleanedState)
		}
	}
	data := responses.ChatResponse{
		Chat: *chat,
	}

	w.Header().Set("Content-Type", "application/json")
	json.NewEncoder(w).Encode(data)
	return nil
}

// awaitToolApproval returns nil when the call may proceed. It returns an error
// when the user declined, when nobody answered, or when the chat ended — and in
// every one of those cases the tool must not run.
//
// A tool that does not require approval, a scope the chat has already
// granted, or any call made while the settings switch approves every tool
// call, returns immediately without asking.
func (s *Server) awaitToolApproval(ctx context.Context, w http.ResponseWriter, flusher http.Flusher, chatID string, registry *tools.Registry, toolName string, args map[string]any) error {
	tool, ok := registry.Get(toolName)
	if !ok {
		// An unknown tool is refused by Execute with a clearer message; there
		// is nothing to approve.
		return nil
	}
	if !tools.ToolRequiresApproval(tool, args) {
		return nil
	}

	approvals := s.approvals()
	scope := tools.ToolApprovalScope(tool, args)
	if approvals.State(chatID).Allows(scope) {
		return nil
	}
	if s.autoApprovesTools(chatID, toolName, scope) {
		return nil
	}

	request := tools.ApprovalRequest{
		ID:       tools.NewRequestID(chatID),
		ChatID:   chatID,
		ToolName: toolName,
		Scope:    scope,
		Args:     args,
	}

	decision, err := approvals.Await(ctx, request, func(req tools.ApprovalRequest) error {
		if encodeErr := json.NewEncoder(w).Encode(responses.ChatEvent{
			EventName:     "tool_approval",
			ToolName:      &req.ToolName,
			ApprovalID:    &req.ID,
			ApprovalScope: &req.Scope,
			ApprovalArgs:  req.Args,
		}); encodeErr != nil {
			return encodeErr
		}
		flusher.Flush()
		return nil
	})
	if err != nil {
		return fmt.Errorf("%s was not run: %w", toolName, err)
	}
	if !decision.Allow {
		return fmt.Errorf("%s was not run because you declined it", toolName)
	}
	return nil
}

// approvals returns the approval rendezvous, creating it on first use so a
// Server built without one still refuses tools that need approval rather than
// running them.
func (s *Server) approvals() *tools.Approvals {
	s.approvalsOnce.Do(func() {
		if s.Approvals == nil {
			s.Approvals = tools.NewApprovals()
		}
	})
	return s.Approvals
}

// autoApprovesTools reports whether the user has switched off approval prompts
// for every tool call, and records the call it is letting through.
//
// The switch is read from the store on every call rather than held in memory,
// for the same reason the MCP approval ledger is re-read on every question:
// the user changes it while the app is running and expects the next call to
// obey it. A call already waiting for an answer is not released by switching
// it on — that question was put to the user and stays theirs to answer.
//
// Without a store there is no switch, and a store that cannot be read leaves
// the question to the user, which is where it was before the switch existed;
// neither failure runs a tool that nobody agreed to.
func (s *Server) autoApprovesTools(chatID, toolName, scope string) bool {
	if s.Store == nil {
		return false
	}
	settings, err := s.Store.Settings()
	if err != nil {
		s.log().Warn("could not read settings; asking for tool approval instead", "chat", chatID, "tool", toolName, "error", err)
		return false
	}
	if !settings.AutoApproveTools {
		return false
	}
	s.log().Info("tool call approved automatically by the settings switch", "chat", chatID, "tool", toolName, "scope", scope)
	return true
}

// chatApproval carries the user's answer back to the tool call that is waiting
// for it. The waiting call is inside a different, still-open HTTP response, so
// the two meet through the approvals registry rather than through this request.
func (s *Server) chatApproval(w http.ResponseWriter, r *http.Request) error {
	cid := r.PathValue("id")
	if cid == "" {
		return fmt.Errorf("chat ID is required")
	}

	var body struct {
		ApprovalID  string `json:"approvalId"`
		Allow       bool   `json:"allow"`
		Remember    bool   `json:"remember"`
		RememberAll bool   `json:"rememberAll"`
	}
	if err := json.NewDecoder(r.Body).Decode(&body); err != nil {
		w.WriteHeader(http.StatusBadRequest)
		return fmt.Errorf("invalid request body: %w", err)
	}
	if body.ApprovalID == "" {
		w.WriteHeader(http.StatusBadRequest)
		return fmt.Errorf("approvalId is required")
	}
	// An approval belongs to the chat it was raised in. Without this check one
	// chat could answer another chat's question.
	if !strings.HasPrefix(body.ApprovalID, cid+":") {
		w.WriteHeader(http.StatusBadRequest)
		return fmt.Errorf("approval does not belong to this chat")
	}

	err := s.approvals().Resolve(body.ApprovalID, tools.ApprovalDecision{
		Allow:       body.Allow,
		Remember:    body.Remember,
		RememberAll: body.RememberAll,
	})
	if errors.Is(err, tools.ErrNotPending) {
		w.WriteHeader(http.StatusConflict)
		return err
	}
	if err != nil {
		return err
	}

	w.Header().Set("Content-Type", "application/json")
	return json.NewEncoder(w).Encode(map[string]bool{"ok": true})
}

func (s *Server) deleteChat(w http.ResponseWriter, r *http.Request) error {
	cid := r.PathValue("id")
	if cid == "" {
		return fmt.Errorf("chat ID is required")
	}

	// Nothing may be left waiting on an answer that can no longer be given.
	s.approvals().CancelChat(cid)

	// Check if the chat exists (no need to load attachments)
	_, err := s.Store.ChatWithOptions(cid, false)
	if err != nil {
		if errors.Is(err, not.Found) {
			w.WriteHeader(http.StatusNotFound)
			return fmt.Errorf("chat not found")
		}
		return fmt.Errorf("failed to get chat: %w", err)
	}

	// Delete the chat
	if err := s.Store.DeleteChat(cid); err != nil {
		return fmt.Errorf("failed to delete chat: %w", err)
	}

	w.WriteHeader(http.StatusOK)
	return nil
}

// TODO(parthsareen): consolidate events within the function
func chatEventFromApiChatResponse(res api.ChatResponse, thinkingTimeStart *time.Time, thinkingTimeEnd *time.Time) responses.ChatEvent {
	// If there are tool calls, send assistant_with_tools event
	if len(res.Message.ToolCalls) > 0 {
		// Convert API tool calls to store tool calls
		storeToolCalls := make([]store.ToolCall, len(res.Message.ToolCalls))
		for i, tc := range res.Message.ToolCalls {
			argsJSON, _ := json.Marshal(tc.Function.Arguments)
			storeToolCalls[i] = store.ToolCall{
				Type: "function",
				Function: store.ToolFunction{
					Name:      tc.Function.Name,
					Arguments: string(argsJSON),
				},
			}
		}

		var content *string
		if res.Message.Content != "" {
			content = &res.Message.Content
		}
		var thinking *string
		if res.Message.Thinking != "" {
			thinking = &res.Message.Thinking
		}

		return responses.ChatEvent{
			EventName:         "assistant_with_tools",
			Content:           content,
			Thinking:          thinking,
			ToolCalls:         storeToolCalls,
			ThinkingTimeStart: thinkingTimeStart,
			ThinkingTimeEnd:   thinkingTimeEnd,
		}
	}

	// Otherwise, send regular chat event
	var content *string
	if res.Message.Content != "" {
		content = &res.Message.Content
	}
	var thinking *string
	if res.Message.Thinking != "" {
		thinking = &res.Message.Thinking
	}

	return responses.ChatEvent{
		EventName:         "chat",
		Content:           content,
		Thinking:          thinking,
		ThinkingTimeStart: thinkingTimeStart,
		ThinkingTimeEnd:   thinkingTimeEnd,
	}
}

func chatInfoFromChat(chat store.Chat) responses.ChatInfo {
	userExcerpt := ""
	var updatedAt time.Time

	for _, msg := range chat.Messages {
		// extract the first user message as the user excerpt
		if msg.Role == "user" && userExcerpt == "" {
			userExcerpt = msg.Content
		}
		// update the updated at time
		if msg.UpdatedAt.After(updatedAt) {
			updatedAt = msg.UpdatedAt
		}
	}

	return responses.ChatInfo{
		ID:          chat.ID,
		Title:       chat.Title,
		UserExcerpt: userExcerpt,
		CreatedAt:   chat.CreatedAt,
		UpdatedAt:   updatedAt,
	}
}

func (s *Server) settings(w http.ResponseWriter, r *http.Request) error {
	old, err := s.Store.Settings()
	if err != nil {
		return fmt.Errorf("failed to load settings: %w", err)
	}

	var settings store.Settings
	if err := json.NewDecoder(r.Body).Decode(&settings); err != nil {
		return fmt.Errorf("invalid request body: %w", err)
	}

	if err := s.Store.SetSettings(settings); err != nil {
		return fmt.Errorf("failed to save settings: %w", err)
	}

	// Handle auto-update toggle changes
	if old.AutoUpdateEnabled != settings.AutoUpdateEnabled {
		if !settings.AutoUpdateEnabled {
			// Auto-update disabled: cancel any ongoing download
			if s.Updater != nil {
				s.Updater.CancelOngoingDownload()
			}
		} else {
			// Auto-update re-enabled: show notification if update is already staged, or trigger immediate check
			if (updater.IsUpdatePending() || updater.UpdateDownloaded) && s.UpdateAvailableFunc != nil {
				s.UpdateAvailableFunc()
			} else if s.Updater != nil {
				// Trigger the background checker to run immediately
				s.Updater.TriggerImmediateCheck()
			}
		}
	}

	if old.ContextLength != settings.ContextLength ||
		old.Models != settings.Models ||
		old.Expose != settings.Expose {
		s.Restart()
	}

	w.Header().Set("Content-Type", "application/json")
	return json.NewEncoder(w).Encode(responses.SettingsResponse{
		Settings: settings,
	})
}

func (s *Server) modelUpstream(w http.ResponseWriter, r *http.Request) error {
	if r.Method != "POST" {
		return fmt.Errorf("method not allowed")
	}

	var req struct {
		Model string `json:"model"`
	}
	if err := json.NewDecoder(r.Body).Decode(&req); err != nil {
		return fmt.Errorf("invalid request body: %w", err)
	}

	if req.Model == "" {
		return fmt.Errorf("model is required")
	}

	digest, pushTime, err := s.checkModelUpstream(r.Context(), req.Model, 5*time.Second)
	if err != nil {
		s.log().Warn("failed to check upstream digest", "error", err, "model", req.Model)
		response := responses.ModelUpstreamResponse{
			Error: err.Error(),
		}
		w.Header().Set("Content-Type", "application/json")
		return json.NewEncoder(w).Encode(response)
	}

	n := model.ParseName(req.Model)
	stale := true
	if m, err := manifest.ParseNamedManifest(n); err == nil {
		if m.Digest() == digest {
			stale = false
		} else if pushTime > 0 && m.FileInfo().ModTime().Unix() >= pushTime {
			stale = false
		}
	}

	response := responses.ModelUpstreamResponse{
		Stale: stale,
	}

	w.Header().Set("Content-Type", "application/json")
	return json.NewEncoder(w).Encode(response)
}

func userAgent() string {
	buildinfo, _ := debug.ReadBuildInfo()

	version := buildinfo.Main.Version
	if version == "(devel)" {
		// When using `go run .` the version is "(devel)". This is seen
		// as an invalid version by ollama.com and so it defaults to

		// checks can be skipped by using the special version "v0.0.0",
		// so we set it to that here.
		version = "v0.0.0"
	}

	return fmt.Sprintf("ollama/%s (%s %s) app/%s Go/%s",

		runtime.GOARCH,
		runtime.GOOS,
		version,

// isImageAttachment checks if a filename is an image file
func isImageAttachment(filename string) bool {
	ext := strings.ToLower(filename)
	return strings.HasSuffix(ext, ".png") || strings.HasSuffix(ext, ".jpg") || strings.HasSuffix(ext, ".jpeg") || strings.HasSuffix(ext, ".webp")
}

// buildChatRequest converts store.Chat to api.ChatRequest
func (s *Server) buildChatRequest(chat *store.Chat, model string, think any, availableTools api.Tools, mcpInstructions string) (*api.ChatRequest, error) {
	var msgs []api.Message
	// The servers' own words, ahead of the conversation. A tool definition says
	// what one call does; this is the only place a server can say what it is
	// for, which is what decides whether a model reaches for it unprompted.
	if strings.TrimSpace(mcpInstructions) != "" {
		msgs = append(msgs, api.Message{Role: "system", Content: mcpInstructions})
	}
	for _, m := range chat.Messages {
		// Skip empty messages if present
		if m.Content == "" && m.Thinking == "" && len(m.ToolCalls) == 0 && len(m.Attachments) == 0 {
			continue
		}

		apiMsg := api.Message{Role: m.Role, Thinking: m.Thinking}

		sb := strings.Builder{}
		sb.WriteString(m.Content)

		var images []api.ImageData
		if m.Role == "user" && len(m.Attachments) > 0 {
			for _, a := range m.Attachments {
				if isImageAttachment(a.Filename) {
					images = append(images, api.ImageData(a.Data))
				} else {
					content := convertBytesToText(a.Data, a.Filename)
					sb.WriteString(fmt.Sprintf("\n--- File: %s ---\n%s\n--- End of %s ---",
						a.Filename, content, a.Filename))
				}
			}
		}

		apiMsg.Content = sb.String()
		apiMsg.Images = images

		switch m.Role {
		case "assistant":
			if len(m.ToolCalls) > 0 {
				var toolCalls []api.ToolCall
				for _, tc := range m.ToolCalls {
					var args api.ToolCallFunctionArguments
					if err := json.Unmarshal([]byte(tc.Function.Arguments), &args); err != nil {
						s.log().Error("failed to parse tool call arguments", "error", err, "function_name", tc.Function.Name, "arguments", tc.Function.Arguments)
						continue
					}

					toolCalls = append(toolCalls, api.ToolCall{
						Function: api.ToolCallFunction{
							Name:      tc.Function.Name,
							Arguments: args,
						},
					})
				}
				apiMsg.ToolCalls = toolCalls
			}
		case "tool":
			apiMsg.Role = "tool"
			apiMsg.Content = m.Content
			apiMsg.ToolName = m.ToolName
		case "user", "system":
			// User and system messages are handled normally
		default:
			// Log unknown roles but still include them
			s.log().Debug("unknown message role", "role", m.Role)
		}

		msgs = append(msgs, apiMsg)
	}

	var thinkValue *api.ThinkValue
	if think != nil {
		// Only set Think if it's actually requesting thinking
		if boolValue, ok := think.(bool); ok {
			if boolValue {
				thinkValue = &api.ThinkValue{Value: boolValue}
			}
		} else if stringValue, ok := think.(string); ok {
			if stringValue != "" && stringValue != "none" {
				thinkValue = &api.ThinkValue{Value: stringValue}
			}
		}
	}

	req := &api.ChatRequest{
		Model:    model,
		Messages: msgs,
		Stream:   ptr(true),
		Think:    thinkValue,
	}

	if len(availableTools) > 0 {
		req.Tools = availableTools
	}

	return req, nil
}

		_, err = db.Exec("UPDATE messages SET stream = 'invalid_boolean' WHERE chat_id = ?", chat.ID)
		must(err)
	}
	countOriginals := func() int {
		var n int
		must(db.QueryRow("SELECT COUNT(*) FROM messages WHERE chat_id = ? AND content IN (?, ?)", chat.ID, "original user message", "original assistant message").Scan(&n))
		return n
	}
	result := observation{Case:name, OriginalMessagesBefore:countOriginals()}
	_, err = s.ChatWithOptions(chat.ID, true)
	if err != nil {
		result.StoreError = err.Error()
		result.ClassifiedNotFound = errors.Is(err, not.Found)
	}
	var hits atomic.Int32
	model := httptest.NewServer(http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		hits.Add(1)
		w.Header().Set("Content-Type", "application/json")
		switch r.URL.Path {
		case "/api/show":
			fmt.Fprintln(w, `{"capabilities":["completion"]}`)
		case "/api/chat":
			fmt.Fprintln(w, `{"model":"probe-model","message":{"role":"assistant","content":"acknowledged"},"done":true}`)
		default:
			http.Error(w, "unexpected model operation", 500)
		}
	}))
	defer model.Close()
	must(os.Setenv("OLLAMA_HOST", model.URL))
	// Development-mode HTTP entry point: this diagnostic does not test authentication.
	server := &ui.Server{Store:s, Dev:true, Logger:slog.New(slog.NewTextHandler(io.Discard, nil))}
	endpoint := httptest.NewServer(server.Handler())
	defer endpoint.Close()
	request, err := http.NewRequest(http.MethodPost, endpoint.URL+"/api/v1/chat/"+chat.ID, strings.NewReader(`{"model":"probe-model","prompt":"new message"}`))
	must(err)
	request.Header.Set("Content-Type", "application/json")
	client := &http.Client{Timeout:10*time.Second}
	response, err := client.Do(request)
	must(err)
	body, err := io.ReadAll(response.Body)
	response.Body.Close()
	must(err)
	result.HTTPStatus = response.StatusCode
	result.HTTPBody = string(body)
	result.ModelRequests = hits.Load()
	result.OriginalMessagesAfter = countOriginals()
	rows, err := db.Query("SELECT content FROM messages WHERE chat_id = ? ORDER BY id", chat.ID)
	must(err)
	for rows.Next() {
		var text string
		must(rows.Scan(&text))
		result.ContentsAfter = append(result.ContentsAfter, text)
	}
	must(rows.Err())
	rows.Close()
	return result
}

func main() {
	if len(os.Args)!=2 { fmt.Fprintln(os.Stderr,"usage: chat_read_probe OUTPUT_DIRECTORY"); os.Exit(2) }
	base := os.Args[1]
	must(os.Mkdir(base,0700))
	results := []observation{}
	failed := false
	for _, name := range []string{"healthy", "malformed", "missing"} {
		o := runCase(name,base)
		results = append(results,o)
		if name=="malformed" {
			failed = failed || o.ClassifiedNotFound || o.ModelRequests!=0 || o.HTTPStatus!=500 || o.OriginalMessagesAfter!=o.OriginalMessagesBefore
		} else {
			failed = failed || o.HTTPStatus!=200 || o.ModelRequests!=3 || o.OriginalMessagesAfter!=o.OriginalMessagesBefore
		}
	}
	data,err := json.MarshalIndent(results,"","  ")
	must(err)
	must(os.WriteFile(filepath.Join(base,"observations.json"),append(data,'\n'),0600))
	fmt.Println(string(data))
	if failed { fmt.Fprintln(os.Stderr,"CHAT_READ_INTEGRITY=FAIL"); os.Exit(1) }
	fmt.Println("CHAT_READ_INTEGRITY=PASS")
}
